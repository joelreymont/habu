Define STRUCTURE rows for operation metadata and adjoint metadata, use bool for support and option<opkind> for the backward operation, and store rows in typed layout buffers keyed only through opkind conversion. Keep the reference execution-token column separate under habu-typed-xt-cell-4c8ecc4c. Replace case/default chains with exhaustive MATCH and remove duplicated range checks/sentinels. Coordinate habu-require-maki-op-b14ccc89 so its CAD effect field extends the canonical operation row rather than creating another parallel table. Preserve every row, registry ordering, public decision, emitted backward graph, numerical gradients, and exact wire identities. Add checker negatives for every pairwise semantic-field swap, invalid support/absence states, row/key mismatch, and foreign enums; exhaustive row round trips and mutation tests cover every enum variant and op. Measure JIT/DATA/CODELEN, table bytes, lookup/build latency, and graph/PTX output before/after. Files: maki/op-registry.f, maki/adjoint.f and focused consumers/tests.
