Problem: the checked inference path cannot own authenticated GPT-2 weights on the GPU. Result: package GPT2 owns one linear `model` structure containing `GPU:session`, `GPU:buffer`, and `GPT2:config`; `OPEN ( FS:path -- result<GPT2:model,n> )`, `CLOSE ( GPT2:model -- result<n,n> )`, and pure `SPAN ( GPT2:config GPT2:tensor-id -- GPT2:config CAD-NUM:byte-off CAD-NUM:byte-len )` are the complete new public surface. `SPAN` computes the canonical dense layout directly from the frozen 4+13-per-layer tensor vocabulary with checked arithmetic; total allocation bytes stay private. `OPEN` reads the pinned config, maps `model.safetensors` once through `SAFET:file`, validates the pinned whole-file SHA-256 and exactly the expected census, names, datatypes, ranks, dimensions, and byte lengths before any GPU call, detaches that same mapping, opens one GPU session, allocates one buffer, and performs one synchronous `GPU:UPLOAD` per tensor from `SAFET:MAP-OFFSET?` into its canonical `SPAN`. It reuses one scoped host scratch for path, digest, and tensor name; it creates no host weight copy or persistent descriptor table. Generalize only the existing `SAFET:WITH-MAPPING` stack effect to the established `R`/`S` scoped-callback form so the callback can consume an offset/length and return an error code while retaining `SAFET:mapping`; add no SAFET word or state. Every refusal preserves the first error, releases each acquired SAFET/GPU owner exactly once, and publishes no model; success unmaps/releases SAFET state before constructing the model. `CLOSE` frees the buffer before closing the session and returns the first cleanup error. Owner: GPT-2 model lifetime, canonical GPU weight layout, and direct authenticated upload only. Production red: the current `SAFET:WITH-MAPPING` rejects the real `GPU:UPLOAD` caller chain because its hidden input/output prefix is fixed, and no `GPT2:model`/`OPEN` exists. Acceptance: CPU tests prove transformed-row mapping callbacks, exact `SPAN` offsets/non-overlap/total size, catalog refusal before GPU ownership, and cleanup counts; the DGX test opens the real pinned root through `GPT2:OPEN`, observes all uploads succeed, closes it, and leaves GPU/SAFET live-owner counts at baseline. Forbidden: GPT2DEV, DEVRT, MODEL-ASSET, staging owners, descriptor/offset tables, bounce or full-host buffers, raw device pointers, public byte totals, special error/result types, globals for owner state, manifests, registries, retries, lazy load, ABI versions, compatibility, or forward/decode work. Smallest owning checks: `bin/hb --load maki/infer/gpt2-model-test.f` and the same production-entry test on DGX Spark with the real pinned root.
