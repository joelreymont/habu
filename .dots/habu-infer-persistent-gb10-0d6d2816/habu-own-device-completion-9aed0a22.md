Why: cache finalization cannot rely on a caller statement that device access stopped, but DEVRT must not own or consume a KV type. Result: DEVRT declares pending, poison, DONE, and QUIESCED as public linear owner products with no public constructors. DEVRT alone constructs them; a consuming foreign package may destructure only their non-authoritative session generation and cannot mint or substitute the nominal proof. The first accepted model-prepared enqueue consumes DEVRT:session and returns enqueued(pending,outcome); refusal before any enqueue returns refused(session,code), while refusal after an enqueue returns enqueued(pending,failed(code)). SYNC ( DEVRT:pending -- DEVRT:sync-result ) returns complete(session,DONE,outcome) only after the exact stream is quiescent, or poison(DEVRT:poison,code) when synchronization cannot prove quiescence. Outcome is a typed success|failed(code) union, never an error-as-state. QUIESCE ( DEVRT:poison -- DEVRT:quiesce-result ) destroys the CUDA context and returns closed(QUIESCED) carrying the session generation only when no device access remains, or refused(poison,code). DONE and QUIESCED contain only the device-session generation, are single-use, and contain no cache, descriptor, batch, or operation identity. The one linear session becomes one pending owner at first enqueue, so no other batch can interleave before SYNC or QUIESCE. A poisoned session can never launch again. Dependency: persistent DEVRT session and owner-product construction. Owner: sole completion-carrier declarations, DEVRT enqueue, synchronization, poison, and teardown proof only. Production red: synchronization failure currently mints DONE and the required proofs have no legal cross-package carrier. Acceptance: foreign construction of every carrier rejects before lowering; first-enqueue refusal, mid-enqueue failure, success/failure outcome, sync failure, teardown refusal, and successful quiescence follow the exact result arms; stale, reused, cross-session, and generation-swapped proofs reject; the package contains no KV or model word. Forbidden: KV or descriptor input, application operation identity, public constructor, field authority, boolean flag, integer token, timestamp, magic range, async API, reusable poisoned session, version, or compatibility shim. Smallest owning check: bin/hb --load maki/infer/device-runtime-test.f on DGX Spark.
