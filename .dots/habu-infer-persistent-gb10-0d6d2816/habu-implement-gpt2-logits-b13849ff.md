Why: the landed GPT2:model owns authenticated GPU weights but cannot execute them. Result: extend that sole owner in maki/infer/gpt2-model.f. OPEN allocates exactly one GPU:buffer containing weights, three reusable 4*nembd F32 scratch rows, one F32 vocabulary logit row, one token-id cell, and per-layer contiguous F32 K and V; it emits and compiles the landed tensor and attention sources into two transient cubins, loads exactly two private modules, resolves exactly seven private function handles, removes transient files, and publishes only after all resources exist. GPT2:LOGITS ( GPT2:model n ptr u8 CAD-NUM:byte-len -- GPT2:model result<n,n> ) validates token, current position, and exact nvocab*4 destination length before launch; executes embedding, exactly nlayer GPT-2 blocks, final LayerNorm, tied unembed, context synchronization, and GPU:DOWNLOAD; increments private next-position only after synchronized download succeeds. A failed call returns the same model with position unchanged; any partial current KV row is uncommitted and the next call overwrites that same row before reading it. GPT2:RESET ( GPT2:model -- GPT2:model ) sets only next-position to zero because subsequent attention is bounded by position and overwrites current K/V. CLOSE attempts attention-module unload, tensor-module unload, buffer free, and session close in that order, returns the first error, and releases the host record. GPT2 is the second production CUDA consumer after the GPU owner and introduces no general runtime. The private GPU:SPAN to raw CUDA argument crossing must document the pointer-lifetime checker gap and its live retirement owner. Cubins are transient build provenance only; only module/function handles persist, and modules unload before buffer/session. Dependencies: landed GPU session/buffer/span/download, GPT2:model weight owner, tensor emitter, and attention emitter. Owner: direct GPT2:model device execution and position only. Acceptance: a mandatory standalone DGX Spark test with no skip runs all seven entries through GPT2:LOGITS on the pinned model; token 15496 at position zero matches all eight GPT2-REFERENCE logits with absolute error at most 0.125, full-row sum absolute error at most 256, full-row sumsq absolute error at most 32768, any NaN or Inf fails, and argmax is REAL-ID 0; a second step matches REAL-ID 1; RESET makes the first full row repeat bit-for-bit; invalid token, full context, wrong output length, module/load/launch/sync/download failure preserve ownership and position; two models coexist and close in either order with zero source/GPU owner leaks. Tests use the production OPEN/LOGITS/RESET/CLOSE path. Forbidden: GPT2DEV, DEVRT, paged cache, descriptor, registry, ABI version, compatibility arm, generic graph/runtime, host fallback, per-layer or per-call allocation, per-call module load, second model/cache/session owner, public raw handle, committed binary, suite enrollment, skip logic, manifest, or lint.
