Location: stdlib.habu or compile.zig
Syntax:

  (substitute-if new pred seq &key from-end count start end key)
  (nsubstitute new old seq ...) - destructive version
Examples:
  (substitute 'x 'b '(a b c b d)) => (a x c x d)
