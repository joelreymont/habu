Why: the model now generates correctly, but each command pays the 146-second authenticated open. The smallest useful vLLM-replacement surface is one persistent process that keeps that exact model alive across bounded completion requests.

Result: package `GPT2-SERVE` in `maki/infer/gpt2-serve.f` owns one serial stdin/stdout loop and its private fixed buffers. `bin/hb --load tools/gpt2-serve.f -- <model-root>` calls it directly. Every frame begins with one `u32-le body_len` that counts every byte after the prefix. A request body is `u32-le max_tokens` followed by 0..4096 prompt bytes, so request `body_len` is exactly 4..4100 and 4096 is `GPT2-GEN:PROMPT-CAP`, not a repeated literal. A response body begins with a one-byte tag: tag 0 means success and is followed only by decoded continuation bytes; tag 1 means refusal and is followed by the exact signed Habu error as `i64-le`, so every refusal has `body_len = 9`. Success `body_len` is one plus the decoded byte count. Prompt storage is exactly `GPT2-GEN:PROMPT-CAP`; output storage is exactly `GPT2-GEN:OUTPUT-CAP`. No wire, request, response, or tag type is declared.

The command authenticates BPE and opens `GPT2:model` once, then repeatedly reads one complete request across arbitrary short reads, writes one complete response across arbitrary short writes, and threads the same model to the next iteration. Clean EOF before any prefix byte closes the model and exits zero. EOF after any prefix byte or during a body, request `body_len` outside 4..4100, read failure, or write failure is fatal: it closes the model once and exits nonzero because the stream cannot be resynchronized. After a complete body is present, the service alone prevalidates the wire-checkable facts `prompt_len > 0` and `0 < max_tokens <= GPT2-GEN:MAX-TOKENS`; an invalid value writes `GPT2-GEN:E-PROMPT` or `GPT2-GEN:E-LIMIT` and continues without calling `GENERATE`. It then calls the sole `GPT2-GEN:GENERATE`. Any refusal crossing that call boundary writes the exact tagged error, closes the model, and terminates nonzero because inference or decode may already have mutated model state; the service never classifies the numeric code. An over-context or BPE-refused prompt is therefore terminal until a second independent client exists and justifies a separately typed pre-mutation seam. Private transport helpers return explicit outcomes; no quotation passed to `catch` receives, captures, or consumes the live model. Shutdown retains the first failure while still performing the one model close. Stdin and stdout remain process-owned and are not closed by the service. Framing refusal uses one named `GPT2-SERVE:E-FRAME = -5668`; raw read and write failures use the existing `E-FS-IO`.

No new shared type or generic frame package is permitted. Owner: this one model-specific binary protocol, exact stdio loop, command entry, and its tests only. Production red: no command can serve a second prompt without reopening and reauthenticating the model. Acceptance: the real child opens through a test-owned alias root, receives good `Hello`, and returns its exact tagged pinned continuation. The test then renames that alias root out of reach before sending a fully framed max_tokens-zero refusal and good `Hello` again; the exact second continuation proves the child retained the already authenticated BPE and model rather than reopening. EOF with the alias still absent closes the model and exits zero with clean stderr. Focused tests drive the real private codec over real pipe descriptors and prove exact body-length referents, tags, clean EOF, representative prefix/body splits, partial prefix, partial body, oversized length, and read error without copying the codec or adding an I/O abstraction. Owner counts return to baseline. Forbidden: HTTP, Unix or IPv4 socket, JSON, OpenAI schema, scheduler, connection, poll, concurrent request, stream token response, request id, model registry, daemon, signal handler, thread, generic codec, dynamic allocation, retry, ABI/version, compatibility, metric, manifest, lint, suite, fallback, Python, or shell server. Smallest owning checks: `bin/hb --load maki/infer/gpt2-serve-test.f` for the real codec and `bin/hb --load maki/infer/gpt2-serve-device-test.f -- gpt2-model` for the exact production command.
