Implement sequence quantifier predicates.
Location: stdlib.habu
Syntax:
  (every pred seq &rest more-seqs) - true if pred true for all
  (some pred seq &rest more-seqs) - first non-nil pred result
  (notevery pred seq &rest more-seqs) - true if pred false for some
  (notany pred seq &rest more-seqs) - true if pred false for all
Examples:
  (every #'evenp '(2 4 6)) => t
  (some #'evenp '(1 2 3)) => t
Blocked by: mapcar (for multi-sequence support)
