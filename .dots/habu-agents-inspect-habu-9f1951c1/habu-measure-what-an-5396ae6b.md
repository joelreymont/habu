Problem: the campaign builds inspection words for a live REPL, and nothing had measured where agents spend their calls. Second review, 2026-11-10, over the Claude Code transcripts of this repository since 2026-11-01 (regular-expression counts, a hand sample of the matches checked): reading and searching are 74% of agents' tool calls, with a median 29 calls before the first edit; about a quarter of calls look up Habu words; hb is fed a REPL on stdin in 185 of 13,857 runs, so a word reachable only in a live session is rarely where agents are. Of 817 undefined-word refusals, 53% name a word defined in the Habu source but not visible where it was used and 31% a word Habu does not have (bye, 112 times); for a library or private word that is not loaded, SEE prints 'xref: not found'. A stack mismatch, the moment the typed-state observation serves, is 148 of 988 refusal episodes, each reaching a clean run in a median 2-3 calls.
Acceptance: recorded here, with no code. For the 391 undefined-word episodes: from a scan of the source, where each word is defined and why it was not visible where used; the calls each episode took until a clean run (the second review: median 3, 90th percentile 18); and from both, the most a refusal that stated the defining file and the reason could save. A changed refusal is a change to diagnostic output: its design goes to Joel before a worker starts.
Files: none; scripts over the transcripts and the source.
Verify: the recorded numbers and the scripts that produced them.
Depends: none.
Ownership: measurement only. Joel, 2026-11-10: this dot leads the campaign. Claim: unassigned.

Result, 2026-11-10 (the transcripts of habu, maki, tender and zen since 2026-11-01, 453,140 tool calls): of 2,572 raw undefined-word episodes 940 are refusals an agent then worked on; the rest are deliberate probes or a refusal the agent ignored (a trailing `bye` 265 times). The 940 took a median 2 calls to a clean run, 90th percentile 11, 3,750 calls in all, 0.75% of all calls with overlaps counted once; Habu's own transcripts hold 455 of them, median 2, 90th percentile 13. The second review's 817 refusals in 391 episodes counted lines in Habu's transcripts only and did not separate probes, so it does not compare. By reason (episodes, calls): Habu has the word but not where it was used, such as `[:` at top level or a definer inside a body, 105, 539; in no source today 134, 529; public in a package neither opened nor qualified 104, 455; defined only in a test or tool 84, 436; an engine word refused in a checked body or build stage 85, 418; public but its file not loaded 69, 349; private to its package 83, 338; a standard Forth word Habu lacks 173, 283; an engine word missing in that image or load stage 35, 237; qualified with the wrong package 51, 128; defined later in the same file 9, 20. Of the 400 episodes whose word is defined but not visible, the word was loaded in that run or in the same file in 66, not loaded in 86, and the command does not say in 248. Standard words agents acted on: `0>` 45, `hex` 24, `?dup` 10, `pick` 10, `.r` 9, `to` 9, `2*` 7; docs/forth-card.md's absent table lacks `0>`, `bye`, `hex`, `.r`, `to`, `2*` and `cmove`. The most a refusal that stated the defining file and the reason could save is 1,541 calls, 0.34% of all calls, 0.48% with the engine words counted; a line saying what Habu offers for a standard word, 280 calls, 0.06%. Both are upper bounds: they assume the message alone ends every episode, and the classifier still counts some probes (it agreed with a hand-check on 18 of 20 and 9 of 10 episodes). No changed refusal is designed from this: the bound is under half a percent of calls.
