Implement CLOS defclass for defining classes.
Location: stdlib.habu (macro) + runtime support in Zig
Syntax:
  (defclass name (superclass*)
    ((slot-name :initarg :kw :initform form :accessor fn :reader fn :writer fn)*)
    (:documentation string)
    (:metaclass class))
Examples:
  (defclass point ()
    ((x :initarg :x :initform 0 :accessor point-x)
     (y :initarg :y :initform 0 :accessor point-y)))
Implementation phases:
  1. Basic class definition with slots
  2. Single inheritance
  3. Slot options (:initarg, :initform, :accessor)
  4. Multiple inheritance
  5. Metaclasses
