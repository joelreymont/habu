Problem: VERIFY:SOURCE-BUF opens one checker rollback scope, replays PRODUCT through the declaration coordinator, and then retires type-family, schema, and field rows while leaving published DECL-EVENT rows behind. The result is a published FIELD event whose field id throws E-PF-ID. Checker-scope rollback must own all registry lifetimes atomically. Exact design: add one checked module loaded after decl-event, package CHECKER-REGISTRY-SCOPE, as the sole installer of the existing REG-EXT-RB save, restore, and finalize hooks. Move the existing type-family plus schema callbacks behind a sealed package-owned TYPE-REGISTRY-ROLLBACK API and add a sealed package-owned DECL-EVENT-ROLLBACK API whose private strict-LIFO frame captures event provisional and published counts, base field count, field and variant ordinals, current variant, and transaction depth without rewinding serial tokens. SAVE runs type registries then declaration events; RESTORE and FINALIZE run declaration events then type registries. Event restore rejects a changed transaction depth before mutation, scrubs every retired pointer-free event row, restores all captured event marks, and leaves field/type retirement to their owner. Remove the old type-family hook installer; no second installer, generic callback registry, forwarding global, public mutation surface, new TRUSTED boundary, or verifier-specific cleanup. Register and protect the two internal callback packages so later source cannot reopen or invoke them. Acceptance: through real VERIFY:SOURCE-BUF, successful PRODUCT replay and every syntax/field failure restore exact family, schema, field provisional and published, string, declaration-event provisional and published, ordinal, selector, and scope depths; every surviving event resolves a live family and field. SOURCE-BUF-IN-SCOPE retains events and fields until its real caller closes the outer checker scope, then retires both. Direct CHECKER-DEFPRODUCT and public PRODUCT still publish exact DECL, ARITY, and FIELD rows. Nested checker scopes restore only inner rows. Mutations omitting event SAVE, reversing restore order, retaining event counts, or skipping row scrub fail focused production tests. Files: new src/core/checker-registry-scope.f, src/core/type-family.f, src/core/decl-event.f, production load manifests, focused rollback tests, shared candidate inventory, FILEMAP.md, and no checker.f change. Verify production verify-source, product/type declaration, declaration-event, type-family rollback and generated-declaration suites; exact typed-local, package, trust, host, file-map, and dot gates. Ownership: checker-scope registry composition and declaration-event rollback lifetime only. Depends on habu-consume-registry-events-efe7fe5e for exact package-diff parsing of adjacent raw registry rows.
