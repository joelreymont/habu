Implement generalized place modification.
Location: stdlib.habu (macros) + possibly compiler support
Macros:
  (setf place value pairs*) - generalized assignment
  (psetf place value pairs*) - parallel setf
  (define-setf-expander access-fn lambda-list body)
  (defsetf access-fn update-fn) - simple setf definition
  (get-setf-expansion place &optional env)
Built-in setf places: car, cdr, nth, aref, gethash, symbol-value,
                      slot-value, fill-pointer
Examples:
  (setf (car x) 10) - expands to (rplaca x 10)
  (setf (gethash k ht) v)
  (incf (gethash k ht 0)) - needs (setf (gethash ...) ...)
Currently have: setq only
Important for: incf/decf on places, many idioms
