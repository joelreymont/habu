Problem: NBACK:FREEZE hands every selector one folded module frozen with IR-BUILD:FREEZE-INTERIM (src/compiler/native/backend.f:180-185), which skips schema, dominance, terminator, single-definition, successor-argument and span checks (src/compiler/ir/build.f:1470-1498). Native code is safe because its machine module is verified whole; a Wasm module has none, so the Wasm selector builds a WSTRUCT dialect module with its own schema and freezes it with the full IR-BUILD:FREEZE (build.f:1465-1468) before encoding (wasm-backend.md §5, §5.1, §17.2). The substrate records a region count per schema (src/compiler/ir/schema.f:324) but IR-BUILD has no region builder, so structured control cannot be nested IR regions. wasm-backend.md §4.3 binds code generation to a closed profile (permitted features, maximum arities, locals and module bytes, resource limits) and §3 fixes the baseline as scalar core plus multi-value with every further feature listed individually; CTARGET carries only BASE|SCALAR-FP for wasm (src/compiler/target.f:149 MASK-WASM), so nothing can admit or refuse a feature-gated opcode. Acceptance: package WSTRUCT in src/arch/wasm/wstruct.f, shaped like X64IR (src/compiler/native/x64ir.f:236-242 NAME/MAJOR/MINOR, :1688-1692 NEW-BUILDER, :1848-1863 ENSURE-OP/ENSURE-NAMED): a closed opcode ENUM for the first slice's values (i32, i64, f64 constants, arithmetic, compares, eqz, shifts, wrap and extend, f64 ops, the conversions WPROF admits, reinterpret, select, loads and stores with alignment and offset attributes) and control (br and brz with successor arguments, return, unreachable, call, call_indirect) as a CFG: blocks with typed i32/i64/f64 block arguments, Wasm instructions as operations with alignment, offset and callee-symbol attributes, br, brz, return and unreachable as terminators, call and call_indirect; no block, loop or if operation, since IR-BUILD has no region builder (schema.f:324 records REGION-MAX only); structuring is the encoder's (structure dot); every schema requires CTARGET-ARCH:WASM through IR-SCHEMA:SET-TARGET (schema.f:363 AR-WASM) and f64 forms CTARGET:F-SCALAR-FP (target.f:149 MASK-WASM); i32, i64 and f64 interned as IR types; a module built under a Wasm binding freezes with IR-BUILD:FREEZE. Refusal rows: a use before its definition, a block with no terminator, a successor-argument mismatch, an unregistered opcode, a WSTRUCT op under a non-Wasm binding, each with the substrate's existing code. Package WPROF in src/arch/wasm/profile.f: one closed record with the admitted features (exactly multi-value and saturating-float-to-int), the pinned 16/16 arity, the memory layout (null [0,$10000), ctx [$10000,$11000), OUT [$11000,$21000), stack [$21000,$31000), DATA from $31000; minimum = maximum pages), the ctx field offsets (stack base, top, out-len, throw-code, fault kind, fault address, epoch) and the local, function and module-byte ceilings; `ADMITS?
