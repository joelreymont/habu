Twenty isolated reruns green confirm contention-sensitive timing, not logic. Fix: the already-dead leg synchronizes on ACTUAL child exit or zombie state (waitid WNOWAIT or equivalent through the real primitive surface) before asserting; the assertion then tests the dead path deterministically. Forbidden: timeout increases, retries, or sleep tuning - the race is a wrong synchronization predicate, not a slow box. Owner: the proc-watch smoke suite and, if the honest predicate needs a primitive the surface lacks, STOP and report the missing capability. Acceptance: the smoke suite green under deliberate contention (run beside a competing load, the condition that reds it today); no timing constants changed.

FROZEN FIX (codex, now gate-blocking - deterministic red under the standard-library pool, 20 isolated runs green): CHECK-DEAD must prove the child has actually EXITED before exercising the Linux already-dead pidfd_open path. Do not sleep, increase timeouts, retry the poll, or reap before opening - reaping destroys the zombie contract the fixture exists to test. Add a second child-to-parent exit barrier whose kernel state changes only as part of process death: use the existing process-watch or wait state if it can prove zombie-without-reap (waitid WNOWAIT shape), otherwise redesign the fixture so the parent observes exit without consuming it. Preserve the live-child case and macOS semantics. Acceptance: the focused smoke green under aggregate contention plus the full standard-library gate. Priority raised: gate blocker for the DECL-TX integration. Claim: agent=codex (announced on general, isolated workspace).

DESIGN (codex refinement, frozen): the non-consuming exit barrier is a FIRST watch. Hold the to-be-dead child on a go pipe; the parent opens watch A while the child is provably live, releases the child, and waits for watch A readiness - kernel-observed process death, no reap. Then open watch B on the surviving zombie and assert the already-dead contract (Linux immediate readiness; macOS fail-closed), close both, and only then wait/reap. Delete the racy alive-pipe EOF inference entirely. Deterministic, exercises the production primitive as its own barrier, preserves the exact already-dead contract, needs no new syscall.
