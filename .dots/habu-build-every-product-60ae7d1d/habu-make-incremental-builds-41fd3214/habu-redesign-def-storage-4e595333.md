Problem: the per-definition cache (tools/native-definition-cache.f, hb-def-*.hbd) keeps one container per source file (CONTAINER-PATH :465-475), read whole at open (:591-606) and rewritten whole at close (:639-643) with no lock or merge, and FILE-COMPACT (:631-638) keeps only rows this load hit or stored. Measured and reviewed failures: (1) two engines or alternating builds sharing one root wipe each other to zero hits (~/.cache/tmp/carl-incr-review/zero.md); removing and restoring a word recompiles it. (2) Concurrent builds on one root lose each other's definitions (later rename wins). (3) Stored code carries no payload digest (key = source+context :733-746; NUNIT-FILE checks only magic/version/lengths, native-unit-file.f:104-126; DEF-PREP-OPEN native-unit-object.f:602-605): a flipped code byte is installed silently and runs wrong. (4) An invalid container is reset silently (:602-604). (5) FILE-ROOT$ (:399-402) reads HABU_BUILD_CACHE raw and falls back to <cwd>/.out (~110 MB for a one-line app) while artifacts use BUILD-CACHE tiers (src/lib/build-cache.f); hb-build never exports its resolved root to maker/support children (tools/hb-build-lib.f:712-723, :1466-1470); no BUILD-CACHE:USED/PRUNE covers .hbd;  src/lib/build-input.f:3-4 comment is stale. (6) Engine build into cache C, then widen private RELEASE-RANGE in src/lib/memory.f from ( ptr u8 n -- ) to ( ptr a n -- ) and add public RELEASE-CELLS (diff ~/.cache/tmp/carl-zero/memory.diff): 0 hits / 13945 compiled, while a comment edit keeps 13288 hits. (7) Gate scripts and worker briefs export a fresh HABU_BUILD_CACHE per run, so gates never exercise reuse (test/gate-stdlib-lib.f:71 already shares one root otherwise). Acceptance: storage is per-definition entries (or containers without session compaction) with an object digest checked on load; one root resolved once via BUILD-CACHE:ROOT$ and exported to children, no .out fallback; entries dated and pruned through BUILD-CACHE retention by age/size; concurrent and multi-engine builds on one root keep each other's entries and both products equal the serial product; a corrupt entry is refused with a DIAG line; the memory.f edit in (6) recompiles only memory.f's changed definitions and those that bind RELEASE-RANGE or RELEASE-CELLS; docs/gate.md and docs/bootstrap.md state one persistent cache per checkout and engine; full-suite and two-generation wall time measured before and after. E2Es: A/B engine alternation keeps hits; two concurrent builds then a third reuses both; byte flip refused; variable unset writes nothing under cwd. Needs a Plan design first.
