File: src/compiler/compile.zig (compileUnwindProtect), src/interp/vm.zig (unwind opcode)

Issue: unwind-protect runs cleanup on normal exit but not when error occurs.

Test:
(unwind-protect
  (/ 1 0)           ; error here
  (print cleanup))  ; should run but doesn't

CL Spec: Cleanup forms MUST run even if:
- Error is signaled
- Non-local exit (throw, return-from)
- Normal completion

Current behavior:
- ✅ Cleanup runs on normal exit
- ❌ Cleanup does NOT run on error
- Unknown: cleanup on throw/return-from

Fix approach:
1. Check VM error handling - does it unwind stack properly?
2. Ensure unwind-protect sets up exception handler
3. Cleanup must run before propagating error
4. May need try/finally style implementation

Critical for resource cleanup (file handles, locks, etc.)
