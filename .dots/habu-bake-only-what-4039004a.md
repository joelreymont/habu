Problem: src/habu/native-runtime.f bakes into the engine nine lib files (prelude, errors, image-lifecycle, adt/option, cad-num-types, cad-num-arithmetic, string, memory, vector) and the debugger trio (src/habu/debug.f, stepper.f, debug-watch.f), but only prelude, errors, string, memory and image-lifecycle are required by the compiler itself (src/compiler/**, src/habu/snap.f, app-image-core.f); vector, option, the two cad-num files and the debugger are baked by manifest choice, and cad-num-types is pulled in only because lib/string.f requires it. Joel (2026-09-16): the only packages in the Habu binary should be the compiler, JIT and REPL; everything else is loaded with require; no package or type signature in the image unless the compiler, JIT or REPL requires it. Measured: a bare start is 15 ms and requiring one lib file at tier 0 costs 25-65 ms (task.f 105 defs 36 ms, udp4.f 66 defs 64 ms, at load 7), so a script that requires five lib files pays about a quarter of a second more per start; built applications (hb-build) bake their own closure and pay nothing. Acceptance: (1) the manifest is derived from the closure of the compiler, JIT and REPL entry points (src/core, src/habu emitters and boot, src/compiler, src/os, lib files that closure requires) and nothing else; a lint compares the manifest to that closure and refuses a stray file; (2) lib/string.f no longer requires lib/cad-num-types.f (move the numeric text words that need it beside cad-num, or make the dependency a separate file) so cad-num leaves the image; (3) the debugger loads on demand from its REPL command ( at first use, with the same words and tests); (4) engine-size before and after, bare start time and the require cost of the five most-used lib files reported, the gate and downstream suites green (Radar, Tender, Loom and Maki may rely on lib being present at REPL start: audit their launchers and add the requires they need); (5) a follow-up decision recorded: whether a stdlib snapshot image for the REPL is worth the per-start cost. Files: src/habu/native-runtime.f, tools/build-fixpoint.f (BF-APPEND-* manifest rows), lib/string.f, lib/cad-num-*.f, src/habu/repl.f, src/habu/debug*.f, tools/ (the manifest lint), docs/bootstrap.md.
