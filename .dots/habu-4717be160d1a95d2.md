Implement handler-bind for non-unwinding handlers.
Location: src/compiler/compile.zig or stdlib.habu
Syntax:
  (handler-bind ((type handler-fn)*) form*)
Key difference from handler-case:
  - handler-bind does NOT unwind the stack
  - handler can invoke restarts, decline to handle, etc.
Examples:
  (handler-bind ((error (lambda (c) 
                          (invoke-restart 'continue))))
    (cerror "Continue" "Error occurred"))
Implementation: requires VM support for non-unwinding handlers
Blocked by: restart-case
