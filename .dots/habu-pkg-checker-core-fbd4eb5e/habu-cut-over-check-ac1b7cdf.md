Session contract: the process-local session is non-reentrant. RESET disables capture; clears capture pointers, capacities, and lengths; clears options, selection, copied paths/source/label, argument state, counts, and every materialized or run-temporary span. The private selection discriminator is exactly none, source, file, or list; zero length is data, never a sentinel. None means remaining stdin at RUN time. OPT accepts only json-errors, strict-signatures, all-errors, and source-list without leading dashes. The first three are idempotent booleans. source-list is idempotent, changes none to an empty list, changes one selected file to a one-entry list, and rejects source mode. Unknown options and selection collisions emit the existing usage line and throw 64. SOURCE is accepted only from none, copies source bytes and label before returning, permits zero bytes and a zero-byte label, performs no file or engine work, reports source capacity with the existing source-exceeds-capacity diagnostic and code 66, and rejects a label beyond FS-PATH-CAP with E-FS-CAPACITY. FILE copies each path before returning; from none it selects one file, from list it appends up to CHK-MAX-POS, and from source or a second non-list file it emits usage and throws 64. A path beyond FS-PATH-CAP throws E-FS-CAPACITY. An empty list rejects at RUN with the existing usage diagnostic and 64.

Execution contract: RUN alone checks bin/hb availability, creates and cleans temporary files, materializes the selection, executes every current static, preverify, child, and diagnostic phase, and returns the exact caught result instead of throwing it. Missing bin/hb stays code 69 with its current diagnostic; missing files and expanded source overflow stay code 66 with their current diagnostics. RUN always makes one final real cleanup attempt after the execution and private test-hook outcomes; the earliest nonzero execution or hook result remains the returned result. Successful cleanup clears every temporary owner registration, run buffer, counter, dependency record, and checker scope while preserving options and the copied selection. If real cleanup fails, retain exactly the root, source-path, and run-path ownership required to retry cleanup, clear all capture, option, selection, run, counter, dependency, and checker state, and return the primary result or cleanup result under the same earliest-error rule. RESET retries real cleanup, unconditionally clears every non-owner field, and rethrows a cleanup failure while retaining only that retry ownership. A source rerun after successful cleanup reuses the copied bytes and label; file and list reruns reread their copied paths; none consumes the remaining stdin on each run. Capture configuration is private test support. A completed RUN leaves its captured output readable until the next RUN, RESET, CAPTURE-OFF, capture reconfiguration, or cleanup failure; those operations clear capture lengths, and CAPTURE-OFF also clears borrowed capture pointers and capacities.
