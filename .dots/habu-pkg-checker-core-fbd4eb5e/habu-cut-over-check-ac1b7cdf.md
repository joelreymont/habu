Why: checker callers mutate global cells, borrow caller spans, eagerly materialize source, and split selection from execution. This is the one atomic ownership and public-session cutover; splitting that seam would require a second authority or forwarding globals.

Owner and files: package CHECK owns tools/check-core.f and is reopened by tools/check-test-lib.f. Update tools/check.f, tools/check-main.f, and package GATE-DIAGNOSTICS in test/gate-diagnostics-lib.f. Keep the six primitive TRUST axioms for CHECK!, TYPE-RESERVED?, CHECKER-DEFLINEAR, CHECKER-DEFRECORD, CHECKER-SCOPE-START, and CHECKER-SCOPE-DONE before package CHECK so their checker namespace does not change. All executable words, constants, buffers, and cells in check-core.f are private except MAIN ( -- ), RESET ( -- ), CAPTURE-OFF ( -- ), OPT ( ptr u8 n -- ), SOURCE ( ptr u8 n ptr u8 n -- ) with source then label, FILE ( ptr u8 n -- ), and RUN ( -- n ). Existing CHECK:TEST ( -- ) remains the sole test-library export. Do not rename unrelated private CHK-prefixed internals in this leaf.

Session contract: the process-local session is non-reentrant. RESET disables capture; clears capture pointers, capacities, and lengths; clears options, selection, copied paths/source/label, argument state, counts, and every materialized or run-temporary span. The private selection discriminator is exactly none, source, file, or list; zero length is data, never a sentinel. None means remaining stdin at RUN time. OPT accepts only json-errors, strict-signatures, all-errors, and source-list without leading dashes. The first three are idempotent booleans. source-list is idempotent, changes none to an empty list, changes one selected file to a one-entry list, and rejects source mode. Unknown options and selection collisions emit the existing usage line and throw 64. SOURCE is accepted only from none, copies source bytes and label before returning, permits zero bytes and a zero-byte label, performs no file or engine work, reports source capacity with the existing source-exceeds-capacity diagnostic and code 66, and rejects a label beyond FS-PATH-CAP with E-FS-CAPACITY. FILE copies each path before returning; from none it selects one file, from list it appends up to CHK-MAX-POS, and from source or a second non-list file it emits usage and throws 64. A path beyond FS-PATH-CAP throws E-FS-CAPACITY. An empty list rejects at RUN with the existing usage diagnostic and 64.

Execution contract: RUN alone checks bin/hb availability, creates and cleans temporary files, materializes the selection, executes every current static, preverify, child, and diagnostic phase, and returns the exact caught result instead of throwing it. Missing bin/hb stays code 69 with its current diagnostic; missing files and expanded source overflow stay code 66 with their current diagnostics. All run-temporary paths, buffers, counters, dependency state, checker scopes, and cleanup registrations are cleared after success or failure. Options and the copied selection survive RUN. A source rerun reuses the copied bytes and label; file and list reruns reread their copied paths; none consumes the remaining stdin on each run. Capture configuration is private test support. A completed RUN leaves its captured output readable until the next RUN, RESET, CAPTURE-OFF, or capture reconfiguration; those operations clear capture lengths, and CAPTURE-OFF also clears borrowed capture pointers and capacities.

Command contract: MAIN calls RESET, parses the existing CLI spellings --json-errors, --strict-signatures, --all-errors, --source-list, and -- exactly as today through the public operations, calls RUN once, and throws any nonzero result. tools/check.f and tools/check-main.f invoke only CHECK:MAIN. GATE-DIAGNOSTICS configures checks only through public CHECK words. tools/check-test-lib.f uses bare private access only while package CHECK is reopened; do not export a test bridge.

Acceptance: prove caller-buffer mutation cannot change pending source, label, or file selections; empty source differs from none; option repetitions and order are stable; every mode collision, path/source/label capacity, empty list, missing file, and missing engine outcome is exact; repeated success and failure leave no temporary state and preserve selection; captured bytes have the specified lifetime. The actual stdin, one-file, source-list, preverify, all-errors, JSON, nominal, package, and diagnostics entry points remain byte-exact. Run tools/check-test.f, real tools/check.f stdin/file/list probes, gate diagnostics diag-undef-primary, exact ownership/type checks, host lint, and file-map lint. Forbidden: borrowed selection spans, eager SOURCE materialization, sentinel lengths, inferred modes, a public list or capture-on API, aliases, exported storage, compatibility globals, provider qualification before those providers are packaged, or a second session authority. Claim: unassigned.
