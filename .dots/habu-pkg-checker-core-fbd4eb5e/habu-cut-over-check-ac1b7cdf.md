Why: checker callers mutate global cells, borrow caller spans, eagerly materialize source, and split selection from execution. This is the one atomic public-session cutover; splitting it would require a second authority or forwarding globals. Owner: package CHECK. Files: tools/check-core.f, tools/check.f, tools/check-main.f, tools/check-test-lib.f, test/gate-diagnostics-lib.f. Publish only MAIN, RESET, CAPTURE-OFF, OPT, SOURCE, FILE, RUN, plus existing CHECK:TEST. The process-local session is non-reentrant. RESET removes pending-run state, disables capture, clears capture spans, options, selection, paths, labels, counts, and materialized state. Input has a private none/source/file/list discriminator; zero length is data, never a sentinel. OPT accepts only json-errors, strict-signatures, all-errors, and source-list; options are idempotent. Source-list changes none to an empty list or one file to a one-entry list and rejects source mode. SOURCE copies bytes and label immediately, permits empty source only in an otherwise empty non-list session, and performs no file work. FILE copies paths immediately; one file is allowed without list mode, further files require list mode, and source/file modes are exclusive. RUN alone checks file and engine availability, materializes, checks, returns the exact caught result, and clears all run-temporary state on success or throw. Selection/options survive RUN; source reruns reuse owned bytes, file/list reruns reread, stdin consumes remaining input. Capture output lives until RUN, RESET, or capture reconfiguration. MAIN resets, parses through the same operations, runs, and throws nonzero. Acceptance: caller-buffer mutation cannot change selections; empty source differs from no selection; every mode collision and empty list reject; repeated success/failure leaks no temporary state and preserves selection; option ordering matches CLI; diagnostics uses only public CHECK words; command/direct/list/preverify/all-errors/JSON/nominal/package behavior stays byte-exact. Forbidden: borrowed session spans, eager SOURCE materialization, sentinel lengths, inferred modes, public list API, aliases, exported cells/buffers, or second session authority.
