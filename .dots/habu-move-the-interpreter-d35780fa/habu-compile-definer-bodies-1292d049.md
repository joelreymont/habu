Decisions:
1. New `NCOMP:COMPILE-FIXED ( n n -- )` (value, NDICT kind `FIXED-VAL`/`FIXED-ADDR`, `dict.f` ~131-133) in `compiler.f`, built by new `NELAB:FIXED` in `elaborate.f`: a 0-in/1-out function, one `STAGE-LIT` with `HIR:ADDR-DATA` or `ADDR-NONE`, then `EMIT-RETURN`; CALLED?/TAIL/CALLS-BACK clear; then `EMITTED` (shadow via `SHADOWED`) and `NPUB:PUBLISH-PENDING`. Check first whether IR-BUILD accepts a function with no tape span (`OPEN-FUN` reads `NTAPE:SPAN@`/`SPELL@`); if not, open a one-row tape over the def-open name.
2. `definers.f` registers the raw effect after publication through a `TRUSTED: DEF-RAW` that mirrors `LASTC-TRUST:PUBLISH-PTR-A`/`PUBLISH-A` (`habu2.f` ~2744-2794) with the owner-field pattern of `packages.f` PKG-OPERATION: active owner's `RAW-OFF` xt, else (HOOK-CELL set) the target owner's or die naming `trust-raw` rc 70; then the target owner unless the same xt. `-- ptr a` for create and variable, `-- a` for constant. Reproduce the engine's check hook on `"NAME create"`/`"NAME constant"` (C-DEFHOOK ~3228-3235) in the engine's order. Verify whether `NPUB:PUBLISH-PENDING` or `def-close` sets `LASTC-CELL` (create/constant set it; does-patch reads it); if neither, `def-open` with kind ADDR or VAL sets it on both targets.
3. x86 does-patch slot = linkage bit `NBACK:L-PATCH` (beside L-DEAD/L-CALLED/L-TAIL/L-BACK in `compiler.f`), set by COMPILE-FIXED for `FIXED-ADDR`; ARM64 ignores it; x86 (`emit-x64.f` RET) emits `E9 00000000` immediately before the single `ret`. Slot = `start + CODE-SPAN:BODY(len) - 6`; the row checks E9 at slot and C3 at slot+5, else exit 83. Shadow half: new `NSHADOW:PATCH-TAIL ( n n -- )` in `shadow.f` (record index, target; target 0 drops; replaces the row on a second `does>`) records a TAIL site at `emission size - 6` naming the clause; `STAGE-DOES-PATCH` (`elaborate.f` ~4092-4097) calls a Habu `DOES-PATCH` word that runs `does-patch` then `NSHADOW:PATCH-TAIL` when `NSHADOW:OPEN?`.
4. The x86 `does-patch` row does the whole LDOESPATCH contract: rel32 at slot+1 (entry 0 restores `jmp +0`) and DKIND cleared in one PROT window; with `CRSIG-U` nonzero, the owner's `RAW-OFF` xt (active, then target unless same) with LASTC's name and CRSIG; clear `DNAME-WIDE` and min-in; the owner's `REC-WIDE-PUBLISH-OFF` xt; clear CRSIG. Owner fields are xts in DATA cells (`layout.f` ~1093-1096); `DOES-RECORD,` (`kernel-x64.f` ~2206) has the name helpers. ARM64 unchanged.
