The supposedly detached FROM$/TO$/SECTION-OLD$/SECTION-NEW$ accessors all copy through one VIEW-A buffer, so obtaining the second value silently overwrites a retained first value; the mutation test checks only internal artifact survival, not simultaneous returned-view lifetime.
