lib/test/suite.f:19-34 stores suite items in eight parallel columns and groups in three; GROUP-PARALLEL/GROUP-SEQUENTIAL and ITEM-FILE/ITEM-STDIN are raw integers. Passing a mode across these layers silently reverses scheduling, and GROUP-HEADER treats every value other than sequential as parallel. ITEM-ALLOC/GROUP-ALLOC increment counts before later name/stdin/argument parsing and arena writes can throw, leaving counted partial rows and consumed argument bytes.
