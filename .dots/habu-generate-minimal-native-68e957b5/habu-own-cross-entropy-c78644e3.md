maki/xent-train.f is a new library in broad package MAKI that recreates scope with 30+ public/private CET-* names, publishes fixed model dimensions, buffers, learning rate, setup/step/run controls and result getters, and captures MODEL: XENT-MLP at import time. One logical run is split across ambient RNG, parameter/data/seed buffers, shared BW/EX state, step count, and initial/final loss; CET-RUN accepts zero/negative n, writes step count before training, and leaves prior loss cells readable when no iteration records them. Nested, failed, or concurrent runs cross-contaminate process state, and importing the module mutates model IR/dictionary even when no trainer is called. Input slots 0/1/2 are raw constants; CET-GRAD accepts n and only later converts it through MIR-SLOT-ID even though MIR:input-slot already exists. Create a real XENT-TRAIN package with short private tails and one explicit public entry. Put xent-loss-test.f and xent-train-test.f in test-owned packages with short helpers instead of broad MAKI plus XCE-*/XTT-* pseudo-namespaces. Validate steps before publication, build/setup transactionally, return complete results directly, and make throw leave prior state byte-identical or explicitly aborted with owned cleanup. Remove MAKI:CET-* compatibility aliases. Add zero/negative/one-step, setup/build/execute/update injected failures, retry, two independent trainers, import-no-side-effect, old-name rejection, exact deterministic result, source/public-definition/JIT/DATA/CODELEN and retained MODEL-capture measurements.
