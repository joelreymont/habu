maki/lower/ew.f:140-239 and maki/lower/red.f:173-273 independently implement the same region-input and register analysis under LEW-/LRED- prefixes: external-reference classification, linear input lookup/add, MIR input scanning, input collection, materialized-output count/search, ref shape queries, input broadcast classification, node register bounds/map, operand-to-register resolution, and binary operand extraction. Their common elementwise dispatch is duplicated again at ew.f:301-310 and red.f:313-325. maki/lower/mm.f:115-255 repeats the same reference storage, in-region query, materialized-output count/search, reference-shape accessors, and node-register map for the contraction policy. All three modules are loaded together by Maki's whole-model lowering/tests, so the duplicate source also becomes distinct JIT code and duplicated mutable arrays, not merely dormant text. The BCAST-MUL addition proves the change amplification: one operation required 32 production references across 11 files, including copied exhaustive false/error arms in lower/mm.f:147,162,343, lower/move.f:100,180,316, and lower/red.f:134,149,338. The only legitimate difference is class policy: reduction accepts one reduction node plus shared elementwise prologue/epilogue; elementwise accepts only elementwise nodes; matmul selects one contraction and its shape constraints. Root fix: add one package-owned lower/region analysis module with typed region, operand-reference, node-register, input-index, and materialized-output roles; parameterize only the class/op policy and reduction/contraction-specific action, then make EW, RED, and MM thin emission policies over the same analysis result. Do not use parallel prefixed global state or raw callback integers. Fold the shared RELU/GELU/SILU/ADD/BIAS/MUL/SCALE dispatch through one typed op-lowering table. Preserve independent public LEW/LRED/LMM APIs and fail-closed error codes at their boundary. Proof: adding an operation declares its identity and traits once and adds only genuinely distinct execution, adjoint, or lowering behavior; unrelated policies gain no copied false/error arms; source and live-dictionary census removes the duplicate helper families and arrays; snapshot tests pin identical analysis results for all legal broadcast/movement/materialization cases; EW/RED/MM PTX is byte-identical before later optimizer work; every existing negative returns the same named error; Maki host/device, PTX, package/filemap, and full gates pass.
