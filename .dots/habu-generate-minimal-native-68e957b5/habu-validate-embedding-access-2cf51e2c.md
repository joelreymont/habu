Current master embedding memory safety is unchecked. maki/embedding.f EMB-GATHER and EMB-SCATTER-ADD convert arbitrary float ids with f>s and use id*dim without proving finite exact integer, nonnegative, below vocabulary rows, or address overflow; their APIs do not even receive table capacities, so negative, fractional, NaN, infinite, or oversized ids can read or write outside caller buffers. The composed MODEL path is semantically different rather than safer: maki/executor.f EX-BUILD-IDX converts each float with 0.5 f+ f>s, so fractional values can select a different token than the buffer golden before host MOVE-GATHER/SCATTER-ADD range checks, while NaN/infinity still depend on conversion accident. maki/lower/move.f emits the same rounding but performs no id range check before device global-address formation, so id==rows rejects on host yet can read out of bounds on device. New WPE-FIT rejects only t>maxt: negative t/maxt/dim and overflowing t*dim pass into raw ?do/addressing, and WPE-SLICE-ADD has no maxt or buffer capacity at all. Validate the complete request before any read/write through one shared exact token-id decoder/contract used by buffer, executor forward/backward and device lowering: checked nonnegative shape arithmetic, explicit table/output/gradient spans, vocabulary extent, and finite exact bounded token ids. Device code must bounds-check before address formation or consume a host-certified typed id buffer whose provenance cannot be forged. Define the empty-sequence policy; reject invalid dimensions, capacity, multiplication, and every id before publication so gather/scatter failure leaves outputs byte-identical and emits zero device reads. Keep error codes inside the embedding owner. Add -1/0/exact/max+1 dimensions, max-cell products, short spans, first/middle/last bad id, fractional values around both conversion rules, NaN/+Inf/-Inf, negative/out-of-range ids, canaries, no-partial-write, repeated-id accumulation, host/device parity, exact boundary and valid numerical goldens. Coordinate typed representation with a separate embedding ownership dot; this dot owns immediate bounds/value validation. Files: maki/embedding.f, executor index conversion, movement/scatter integration, maki/lower/move.f and focused host/device tests.
