lib/ptx/kernel-abi.f:29-63 declares five closed semantic domains as raw integer constants: logical parameter kind (3), flat-field role (6), field source (4), PTX register class (3), and element type (2). It stores them in generic cell arrays LP-KIND/LP-ELEM/FD-CLASS/FD-ROLE/FD-SRC (:82-96), exposes PARAM-KIND/FIELD-ROLE/FIELD-SRC as n (:334-381), and dispatches with equality chains/default fallthroughs (:174-184, :232-250, :341-344). lib/ptx/kernel-manifest.f:37-47 and :100-105 repeat raw decoding; KIND$ silently maps every non-span/non-matrix value to uniform, ROLE$ maps every unknown value to scalar, and LOWER-PARAM maps every unknown kind to uniform. The shipped ENUM, MATCH, LAYOUT-BUFFER, and TYPED-BUFFER facilities already make these states closed, exhaustive, and storage-safe; keeping raw cells permits class/role/source/kind swaps and manufactured invalid values that the checker cannot reject. Replace all five domains with package-owned ENUMs, migrate each semantic column to LAYOUT-BUFFER/TYPED-BUFFER, give public accessors typed effects, and use exhaustive MATCH for derivation/rendering. Keep explicit wire-number conversion only at a named, bounds-checked serialization boundary if compatibility requires it; no raw n enters internal APIs. Preserve declared ordinals, field layout, manifest strings, PTX bytes, KABI public behavior, and zero-image validity or initialize every slot explicitly if ordinal zero is not semantically valid. Add checker negatives for cross-domain stores/calls, exhaustive-match mutation tests, invalid wire-code rejection, and exact before/after PTX/manifest snapshots. Measure loaded code and DATA before/after and require no growth absent a proven reason. Files: lib/ptx/kernel-abi.f, kernel-abi-test.f, kernel-manifest.f/test, lib/ptx/cg.f, tools/ptx/cuda-launch.f, docs/ptx-sketch.md, FILEMAP.md if the module split changes. Depends: none. Ownership: KABI semantic-domain typing only; kernel-manifest consumer validation remains habu-enforce-kernel-manifest-df5a4f0c.
