Current master defect: tools/ptx/autotune.f:37-55 calls a 15-cell positional array a config record; AT-CFG@/! at 57-58 accept any field index, while AT-DEFAULTS at 61-65, AT-APPLY/AT-SAVE at 96-115, and the twelve 16-cell winner rows at 137-167 hand-maintain the same schema independently. Every axis is n, so same-cell swaps certify and select a different kernel. The drift is already concrete: lib/ptx/cg-mma.f has guard-relevant MMA-ABLATE, and MMA-CHECK-DTYPE reads it, but AT-SAVE/AT-RESTORE omit it; AT-LEGAL? therefore depends on ambient emitter state despite claiming purity. Define one canonical package-owned STRUCTURE mma-config shared by emitter and autotuner, with named refined numeric fields, closed ENUMs for dtype/load/feed modes, and bool switches. Define STRUCTURE winner with shape class plus config in LAYOUT-BUFFER. Legality must consume an immutable config directly instead of mutating and snapshotting ambient globals; generate descriptor completeness from the config so every guard-relevant field is owned once. Preserve every committed winner, selector bucket/error, legality decision, and emitted PTX. Prove compile-negative semantic-field/foreign-enum swaps; descriptor completeness when a guard field is added; ambient-state invariance including ABLATE; all winner round trips and legality; exact PTX for every winner; selector goldens; capacity/canaries. Measure source/JIT/DATA/CODELEN, config storage, and select/check/emit throughput. Coordinate habu-committed-autotune-menu-4321e05d, whose landed raw core this corrects; that dot retains stopwatch/drift/live-wiring ownership.

The advertised menu is not the search space that produced its winners. AT-AXW/M/K/S/N/D at autotune.f:71-85 expose axes for only warps, M-fragments, BK, stages, BN, and dtype. There are no axes for pad, dynamic shared memory, epilogue, load mode, group, split-K, B ldmatrix, B feed, or B pad, yet committed winners require several of those non-default values. A menu enumerator cannot generate its own table. Derive every searchable axis and fixed field from the same config descriptor; prove each committed winner is generated exactly once before pruning and every field is either explicitly searched or deliberately fixed with a named policy. AT-LEGAL? at 130-135 must not turn arbitrary internal throws into bool false: return a payload ENUM legal | illegal(code) for the exact declared guard errors and propagate every unrelated failure after restoring state exception-safely.

The raw schema has already spread: tools/ptx/gemm-bench.f:160-184 adds a nine-n GB-MMM-CFG-SPLIT and handwritten save/restore; tools/ptx/mma-gemm-check.f:728-739 adds a ten-n MGC-CFG-SPLIT and another restore, with dense raw row calls at gemm-bench.f:522-525 and mma-gemm-check.f:884-891. Delete every multi-n config constructor and restore in favor of the same mma-config value. Also define STRUCTURE gemm-shape with refined positive rows/cols/depth. AT-SELECT at autotune.f:205-215 currently accepts raw M/N/K/dtype and buckets unchecked M*N*K; overflow, zero, negative extents, or two negative factors can wrap or multiply into a valid committed band. Product-only bucketing also collapses unmeasured aspect ratios onto square winners without checking the selected tile: M>=BROWS, M%BROWS=0, N%BN=0, K%BK=0, and split constraints exist only in mma-gemm-check.f:204-214. For example 1024x1000x1024 is in-band and receives a winner whose integer grid drops the N tail. Use checked product comparison without overflow, dtype ENUM, and an explicit supported-shape policy before lookup. Legality consumes gemm-shape plus config together; rank only exact-shape-legal winners and return a payload ENUM selected(config) | unsupported(shape) rather than launching a partial kernel. Return config by immutable value, not a mutable pointer into AT-WINNERS that public AT-CFG! can corrupt. Add pairwise role-swap negatives, ragged M/N/K cases, zero-launch assertions, and max-cell/property tests proving invalid, overflowing, unsupported-aspect, or mutated-caller shapes never reach or alter a winner while exact supported floor/midpoint/ceiling behavior stays unchanged.

Delete the unsafe generic surface itself: public AT-CFG@/! at autotune.f:57-58 accept arbitrary negative or oversized field indices and perform unchecked cells+@/!, so the pseudo-record API is a direct out-of-bounds read/write primitive. Public AT-AXIS@ at 79 trusts an unchecked signed index into a length-prefixed array, and AT-WIN-ROW at 165 accepts any signed row index; both can read before or beyond their tables. Generated STRUCTURE accessors plus typed bounded axis and winner indices replace them. Add canaries and -1, count, count+1, 15, and huge-index mutation fixtures proving no generic or raw field/row/axis index path survives and no rejected access performs address arithmetic.

Use the existing package rather than retaining a pseudo-namespace inside it. Nearly every definition in tools/ptx/autotune.f:35-221 keeps an AT-* stem, yielding redundant external spellings such as AUTOTUNE:AT-SELECT. Rename private tails to short package-local names and expose only the narrow SELECT/APPLY surface actually used across the boundary; provide no AT-* compatibility aliases. Prove old prefixed spellings reject, exact consumers use qualified short names, and dictionary name bytes plus loaded JIT/CODELEN do not grow.

The STOPWATCH additions extend the same raw model. autotune.f:243-269 stores exclusions as raw reason constants plus a two-cell table: ADD validates neither candidate id nor reason, ID@/REASON@ accept unchecked signed indexes, TIMED is representable in an excluded-only table, and XR$ maps every unknown reason to timed. autotune-sweep.f returns measurement state through SW-BEST-NS/SW-CLK-MIN/MAX/SW-VALID/SW-ATT globals and adds another large SW-* pseudo-namespace inside package AUTOTUNE, including public AUTOTUNE:AT-SWEEP. Define nominal candidate-id, payload-free exclusion-reason ENUM containing only pruned/inexact/unstable, STRUCTURE exclusion row in bounded typed storage, STRUCTURE clock evidence/sample, and payload-bearing ENUM measurement-outcome = measured(sample) | unstable(evidence). Consume the same typed candidate/config table and bounded shape from habu-bound-autotune-sweep-4fe104ed. Match outcomes exhaustively, remove raw reason/default fallthroughs and unchecked accessors, shorten all private tails, and expose only a qualified SWEEP command API. Add invalid/foreign reason and index negatives, outcome transition/property tests, table canaries, exact report cases, and before/after name/JIT/DATA/CODELEN measurements.

Clock evidence needs real domains, not raw cells. AT-CLK-STABLE? at autotune.f:237-241 accepts arbitrary signed values and compares unchecked products; before=max-cell, after=0, tol=1 wraps `(hi-lo)*1000` negative and falsely classifies total clock collapse as stable. SW-PARSE-MHZ at autotune-sweep.f:198-208 accumulates arbitrary decimal digits through unchecked `*10` and accepts the first digit run in malformed/multi-field output. Define bounded positive MHz and permille types, parse exactly one complete selected-device row with checked decimal accumulation, and compare the ratio without overflow. Add max-cell/zero, either-side zero, long digits, sign/junk, multiple/partial rows, tolerance boundaries, and cross-device fixtures; malformed or overflowed evidence yields a typed probe failure, never stable.

AT-SWEEP is also stateful across its public call boundary: every SW-CANDIDATE applies a config to global MMA knobs, but success leaves the last attempted candidate installed and any caught failure can leave a partially changed MMA/PTX/benchmark state. The final ambient config may even be an inexact or unstable loser. The canonical design must make emit/check consume immutable config values directly. Until all ambient knobs disappear, snapshot and exception-safely restore every guard-relevant emitter, toolchain, and benchmark field around the whole sweep. Prove success, exclusion, contention, probe failure, kernel failure, and injected throws leave caller state byte-identical.
