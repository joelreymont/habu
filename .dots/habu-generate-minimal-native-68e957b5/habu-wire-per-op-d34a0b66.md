Current master semantic/codegen gap after per-op precision grammar landed. maki/prec-attr.f:5-13 claims each node tag selects MMA-DTYPE during device lowering, and CAD accepts MATMUL:FP16, LINEAR:BF16, and equation precision suffixes, but an exact consumer census finds CPREC@ only in backward.f and tests. No lowerer reads the node tag. maki/lower/mm.f:508 still selects tensor-core lowering solely from ambient CLASS-MATMUL PREC@ == PREC-TF32; fp16/bf16 per-op tags therefore change stored attrs and tests but not emitted PTX, operand packing, launch ABI, or runtime computation. A user request such as MATMUL:FP16 silently runs the global f32/tf32 path. Backward propagation is inconsistent too: backward.f:389-410 copies equation precision into adjoint equations, while BW-MM hardcodes attrs=0 and both matmul and linear reverse steps call it, silently reverting their gradients to TF32.

Make precision part of the typed lowering input for every GEMM node: decode and validate attrs at the model-IR boundary; select exact emitter dtype, operand conversion/packing, kernel ABI, numerical license, and evidence from that node value; reject unsupported dtype/config before emission. Define and implement one explicit gradient precision policy for matmul, linear, and equation nodes rather than mixing propagation with attrs=0. For fused regions containing multiple GEMMs, either prove one compatible precision policy or split/reject mixed precision explicitly—never let the last node mutate ambient MMA-DTYPE. Preserve TF32-default byte identity and global licensed-policy behavior for untagged nodes while defining explicit precedence with per-op overrides. Add PTX/disassembly goldens proving TF32/FP16/BF16 emit distinct intended instructions and ABIs, exact forward and adjoint attrs for all three GEMM families, host/device numerical and gradient goldens for each tag, mixed tagged/untagged and mixed-region cases, unsupported-feature rejection, ambient-state restoration after every throw, and evidence/reporting that records the actually executed precision. Measure conversions, emitted PTX/SASS, CODELEN, memory traffic, and device performance. Coordinate representation with habu-structure-precision-policy-fff465ac and half-precision implementation owners; this dot owns end-to-end consumption of the already accepted tag.
