Investigated removing the multi-output-region v1 caps E-LEW-MULTIOUT/E-LRED-MULTIOUT/E-LMM-MULTIOUT (maki/lower-ew.f LEW-FIND-OUT, lower-red.f LRED-FIND-OUT, lower-mm.f LMM-FIND-OUT). VERDICT (A): NO multi-output region is reachable today. FP-ASSIGN (maki/fusion-plan.f) grows each region as a LINEAR operand-0 chain -- FP-JOIN? refuses to join a node into its operand-0 producer P when P FP-REF-USES>1, so any fanned-out producer is a chain TAIL, and FP-MAT-FLAG only materializes tails (model output / multi-use / region-output / mat-movement). Every region therefore has EXACTLY ONE materialized output. Empirically confirmed MAXMAT=1 over a fan-out battery (residual/skip, 3-way fan-out, cross-class, deep 2-point, matmul fan-out, FFN block+skip, hand-built 3-relu and diamond). Delivered: proof test maki/fusion-mout-test.f (wired into maki/test.f), missing EW multiout fail-closed regression added to maki/lower-ew-test.f, and the three caps re-documented as defense-in-depth PLANNER-INVARIANT guards (not v1 caps) in the lowering headers + FIND-OUT sites + the mm/red negative tests. Did NOT build the N-output kernel ABI (p_out0..p_outN-1, N-buffer staging, per-node MDL bind) -- it would be dead machinery: no captured model produces a multi-output region for it to lower. DEFERRED N-output work: only becomes reachable if a future planner change (e.g. region-sharing of a multi-use interior producer to avoid recompute/re-materialization, or a fused multi-head write) can emit a region with >1 materialized node. When that lands: extend the class emitters (LEW/LRED/LMM ENTRY/PARAMS) to N outputs with per-output stores, LLA staging to N buffers, LOWER-MODEL-RUN binding each materialized node, and design the golden to compare the final model output (interior outputs verified transitively). Pending-zed: NONE -- (A) makes no PTX/ABI change, so there are no new device goldens; the invariant battery is host-only planner assertion.
