Problem: tools/lint/clobber-lint-core.f reads the engine's emitter source (src/habu/rt.f crash.f regalloc.f habu1.f jit.f prof.f habu2.f) as text, so it cannot see what host-time code emits: host words (colon words whose bodies emit), registers named by host-time loops ('18 0 ?do i SP i cells STR, loop' in CAPTURE-CUT), quotations of registrars, host words that never return, and a routine's outputs. Lane sealed's fold b counted host words' writes in each routine (path-insensitive) and the engine lint then reported 21 candidates, none judged: habu1.f bpolicyadmit x6 x7 x9 x10 x11 x13 x14 x15 by lrowwalk (EMIT-ROW-WALK hands ROW-TESTS a quotation of row registrars; lrowwalk's comment says it writes x0-x5 only); bcpset x9 by em-def-occ:lreclaim; emit-def-occ-overlap x13 by em-def-occ:lissue; replay-close x4 x5 x6 by em-def-occ:lcount; em-snapshot-restore x6 x7 by em-def-occ:lreset (those routines call CAPTURE-CUT, HOST-INVALIDATE, DEF-OCC-EXHAUSTED); habu2.f emit-esc-copy x9 three times by lescdec and leschex (x9 is their documented output); jit.f recon-consts x7 x8 by lvmovk (C-VMOVK-*); habu2.f walk x12 by lappprov (C-SOURCE-APPEND-PROVIDED); habu2.f em-compile-call x9 by lvspill (VPUSH-ENTRY). Lane sealed's fold d makes an unmodeled host call unknown (pass 2 forgets clobbers, pass 1 adds no writes), so the text lint reports only what it can follow and these stay unchecked. Acceptance: first, each of the 21 judged real or false from the emitted code (the built image: tools/imagedisasm.f, src/arch/arm64/disasm.f), a real one fixed in the engine with a regression; then a design for checking clobbers on the emitted code (routine entries and names from the engine build, the real branch graph, BL targets, each routine's clobber and output contract) that replaces the text lint's host-word guesses, or the evidence that the text lint suffices. Files: tools/lint/clobber-lint*.f, the engine build's label records, docs/gate.md. Verify: the clobber-lint row. Depends: lane sealed landed (habu-answer-tools-check-745b0ccd). Claim: unassigned.
