Enhance defstruct for CL compatibility.
Location: src/compiler/compile.zig (compileDefstruct)
Currently have: basic (defstruct name slot*)
Need:

  (:copier name) - copy function

  (:print-function fn) / (:print-object fn)

  (:type list/vector) - use list/vector representation

  (:initial-offset n) - skip slots

    (y 0 :type fixnum :read-only t))
