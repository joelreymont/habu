File: src/runtime/objects.zig (arrays section), src/compiler/compile.zig (aref/setf handling)

Issue: Only 1D vectors are supported. Multi-dimensional arrays (make-array with :dimensions) are not implemented.

CL Spec requirement:
- (make-array '(3 4)) should create 2D array
- (aref array i j) should access multi-dim elements
- Row-major storage order

Current state:
- ✅ 1D vectors work (make-vector, svref, aref with single index)
- ❌ Multi-dim arrays missing

Fix approach:
1. Extend Vector object to store dimensions list
2. Add dimension rank tracking
3. Implement row-major index calculation: idx = i*dim1*dim2 + j*dim2 + k
4. Update aref/setf to handle multiple indices
5. Add make-array primitive with :dimensions keyword

Files to modify:
- src/runtime/objects.zig: Array/Vector structure
- src/runtime/primitives/vector.zig: Multi-dim support
- src/compiler/compile.zig: aref with multiple indices
