Missing directives:
  ~{ ~} - iteration over list
  ~[ ~] - conditional formatting  
  ~* - goto argument
  ~? ~/ - recursive format, call function
  ~< ~> - justification
  ~P - pluralize
  ~R - radix (english numbers)
  ~F ~E ~G ~$ - floating point formats
