Problem: library code that must reach the process-wide image DATA mapping has no runtime, thread-invariant way to name it. data-base is the calling thread's context (a task's own 64 KiB region on a task), and DATA-VA is a layout constant baked when the source is compiled, which is the TARGET's value when window code runs inside the build host (tools/native-build-core.f PREPARE-TARGET). Measured in batch 4g run 6: forklocks (2149453e) made src/habu/address-cells.f IMAGE = DATA-VA so a fork or a declaration on a task takes the registrar lock the native registrar takes (habu2.f MARK-HEADER uses its own DATA-VA immediate); a foreign-OS native build then SIGBUSes in the macOS host at 0x3400001a8 = Linux DATA-VA + LOCK-CELL (test/native-build-entry F19, F21, F25-28, F31-34; log ~/.cache/tmp/kestrel-r4-batch4g/gate/). With data-base instead, lib/fork-child-test.f's from-task registrar case fails (F22 expected 0 got -2502; F23 expected 32 got 20): a fork on a task holds a lock the registrar never takes, and a task's source declaration races the native registrar. 4g run 7 keeps master's data-base form and drops that case; this dot restores it. The same constant stands in src/core/quotation-storage.f IMAGE-BASE (a window-time STORE in a foreign build would misclassify a DATA cell and skip its xt! declaration) and lib/task.f MAIN-BASE; lib/task.f:1597-1613 records the missing origin as what keeps TASK and FACILITY on create/does>. Acceptance: one engine primitive, emitted by both native targets (habu2.f and kernel-x64.f) from the engine's own layout, answers the running image's DATA mapping as ( -- ptr u8 ) on every thread; address-cells IMAGE, quotation-storage IMAGE-BASE and task MAIN-BASE use it once a release carries it (primitive first, then a release, then the source switch); the from-task registrar case returns to lib/fork-child-test.f and passes; native-build-entry stays green for foreign targets; TASK and FACILITY convert or the note states the remaining reason. Files: src/habu/habu2.f, src/habu/kernel-x64.f, src/habu/address-cells.f, src/core/quotation-storage.f, lib/task.f, lib/fork-child-test.f, test/native-build-entry.f. Ownership: image DATA origin.
