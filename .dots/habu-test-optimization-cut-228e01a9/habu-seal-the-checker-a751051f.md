Problem: checked source can call checker-owner ABI words that only the engine should: on the 9084b558 release engine and on lane 521's g1, `: W ( -- ) s" A" CHECKER-OWNER:USIG-TRUNCATE ;` certifies and runs and afterwards A's records are gone (a later `: B ( n -- n ) A ;` is refused, undefined word A); CHECKER-OWNER:DECLARED-EFFECT, DOES-BEGIN and DOES-FINISH certify and run the same way. Found by review 558 (probes $HOME/.cache/tmp/kestrel-r4-rev558/pr/b1.f, b2.f, b3-base.f, b3-g1.f with their .out files). Fix: refuse every checker-owner entry to checked source by the mechanism lane 521 uses for its own new entries (private or REG-PROTECT, as TRUST-DECL and EFFECT-QUERY-SYM have); census the CHECKER-OWNER and NDICT words checked source can reach and state which each gets. Acceptance: b1-b3 refused (rc 70), each seen running first; the engine's own callers unchanged; baked: rebuild, g1 == g2, two-generation build. After: 7b3f85de.

Still open on master 55cc849f: `: P21 ( ptr u8 n bool -- ) CHECKER-OWNER:DOES-FINISH ;` and `: P22 ( -- ) CHECKER-OWNER:DOES-COMMIT ;` certify (rc 0; review of habu-row-the-checker-6eccc828). The mechanism is package privacy plus the build strip, not owner rows, marks or caller checks: the entries become private to the system package the engine's callers live in.

On the public hb (master 1a41c5ee's engine) `: P21 ( ptr u8 n bool -- ) CHECKER-OWNER:DOES-FINISH ;`, `: P22 ( -- ) CHECKER-OWNER:DOES-COMMIT ;` and `: P24 ( -- ) CHECKER-OWNER:DOES-BEGIN ;` still certify (rc 0, /tmp/jerry-seal/p21.f); USIG-TRUNCATE no longer exists. The same hole is wider than the owner entries: checked source can rebind the checker's own seams with `is`. Of the 141 `defer`s in src/core/checker.f, 130 are never `undefine`d (src/habu/xref.f retires the rest), and the cown lane review measured two on master: a checked body running `[: drop false ;] is TFAM-CELL?-XT` admits a cell-family forge, and `is TFAM-LAYOUT?-XT` admits a cast into another package's OPAQUE structure (/tmp/jerry-cownrv-tmp/rebind-layout2.f). The design covers both: no engine-only checker word, entry or seam, is reachable from checked source.
