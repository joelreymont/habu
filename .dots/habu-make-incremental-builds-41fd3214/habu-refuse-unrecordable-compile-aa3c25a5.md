Acceptance: such a file stores no object and the build names the word (docs/architecture.md "Builds"); every engine and Dots file the frame census reports ordered=1 (native-file: frame lines from the frame dot, with reason and word) whose compile-time code reads an earlier file's state is converted to a typed read, a dictionary record or a declared input, so no engine file is refused.
