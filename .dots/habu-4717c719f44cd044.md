Implement sequence filling and replacement.
Location: stdlib.habu or compile.zig
Functions:
  (fill seq item &key start end) - destructively fill
  (replace seq1 seq2 &key start1 end1 start2 end2) - copy elements
Examples:
  (fill '(a b c d) 'x :start 1 :end 3) => (a x x d)
  (replace "abcd" "XY" :start1 1) => "aXYd"
