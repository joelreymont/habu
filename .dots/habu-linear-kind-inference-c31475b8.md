Static invariant: a DEFLINEAR resource is used exactly once (no duplicate/drop) on ALL paths. src/core/checker.f concrete-count conservation (LIN-SNAPSHOT/LIN-CHECK, checker.f ~969-986) plus the new execute-path conservation (RSEXEC, checker.f ~1040) enforce this for DIRECT copy/drop/leak/double-consume, incl via execute and nested execute. Two residual holes share one root cause: a value duplicated/dropped while its type is a POLYMORPHIC variable that is only later unified with a linear con, so the concrete-count check runs while the value is still a var (count 0). Reproducers (both wrongly PASS): (1) KEEP/BI/TRI - 'CBAD ( own -- own ) [: FREE ;] keep' - KEEP body is 'over >r execute r>'; the 'over' copies a polymorphic a inside KEEP's already-certified body, and at the call site KEEP's stored effect ( R a [R a -- S] -- S a ) uses a in two consuming positions (top-input + quot-input) while count stays neutral (dup+free) -> use-after-free. (2) intra-quotation launder - 'CBAD ( own -- own ) [: dup FREE ;] execute' - dup copies the quot's polymorphic input var, FREE then binds it to own; the quot certifies as [R own -- R own] and applies as an explicit consumer. Fix = proper linear/affine kind discipline: (a) polarity-aware multiplicity at effect application - when unification binds an axiom/user-word type var to a linear con, require exactly-one input-side and exactly-one output-side occurrence across the effect INCLUDING quotation sub-effects (catches dup/drop/over/KEEP/BI/TRI: dup a=1in/2out reject, swap a=1in/1out ok, DIP a=1in/1out ok, KEEP a=2consumed/1produced reject); (b) deferred taint within one body inference - mark a type var non-linearly-used when duplicated/dropped, and reject when it later unifies with a linear con (catches the intra-quotation launder). Gate the whole thing on 'any DEFLINEAR types declared' so non-linear code (the entire gate) pays zero cost and the checker hot path is untouched. Add negative regressions for both reproducers. This is checker-only (src/core/checker.f); no engine change. Blocks discharging the eval-frame/mmap-slot TRUSTED wrappers via a threaded linear frame token.
