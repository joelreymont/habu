Problem: Joel, 2026-09-18, via aspen (Tender): 'why do we not have a tool built into habu that tells us where the size is going? i'm constantly asking where the size is going'. Tender's hb-build --repl images weigh 24.6 MB (scraper only), 28.4 MB (product CLI) and 29.0 MB (server) on an engine of 3.8 MB; tools/imgdump.f itemises only word code (11,368 words, 1.0 MB, about 4 percent of the file) and tools/engine-size.f, which attributes every byte of a baked engine and refuses to report unless the classes sum to the file length, refuses a snapshot image (docs/engine-size.md, What the measurement does not say) and a stripped image; nothing attributes the remaining 23 MB, which by construction is the snapshot's region payload (dictionary DICT-SIZE plus the code band, src/habu/layout.f) and DATA payload written verbatim behind the trailer (SNAP-TRL-REGLEN, SNAP-TRL-DATALEN), zero-filled static allots included. Acceptance: tools/engine-size.f (or a sibling sharing its walkers) attributes every byte of a --repl snapshot image and of a stripped image to a class and an owner with the same sum-to-length refusal: ELF header and padding, engine code, dictionary records and names, code band by package, DATA by owner and package (a static allot charged to its definer), zero-filled spans reported separately from written data, the trailer, relocation and boot-run rows; tools/hb-build.f prints a one-line size summary after every build (total, code, names, data written, data zero-filled, padding) and a --size-report flag prints the full table; docs/engine-size.md gains the application-image section with Tender's numbers as the worked example; a fixture builds a small --repl image and a stripped image and checks the classes sum to the file length. Files: tools/engine-size.f, tools/hb-build.f, tools/hb-build-report.f, tools/imgdump.f (share the trailer reader), docs/engine-size.md, docs/native-applications.md, test/. Verify: the fixture; the tool on bin/hb, on a --repl image and on a stripped image; test/run.f. Depends: none. Ownership: build tools.
