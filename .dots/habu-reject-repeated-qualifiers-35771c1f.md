One qualified call remains allowed. A matching using permits only qualified tokens whose tails are proven ambiguous against the global or another active imported public inventory; all other calls must be bare. Acceptance: hostile comments, strings, duplicate text, reorderings, wrong package, unbalanced scopes, same-tail global collisions, two-package ambiguity, one-off qualification, renamed files, and deleted files prove structural behavior; mutating any token role or count boundary fails. Run the focused suite, self-diff proof, package, typed-local, host, file-map, trust, and native commit gates.
