Why: three lanes converged today on the same missing checker capability, and one produced a rejected commit. The public raw ptr-plus-signed-count compute shape was destruction-rejected twice for GELU! (codex-70ff this morning; commit 1122785b5bfe this evening, where a probe proved n=-1 executes and mutates cell zero and an oversized count has no capacity witness); MM-NT's six same-typed extents let a caller transpose dimensions and still certify; and the T-ADD!/ROW-ADD pair proved identical signatures with opposite argument roles certify interchangeably. Exact result: the frozen design - not implementation - that first compares two candidates and rejects whichever duplicates authority over allocation extent: (A, favored) extend the existing TENSOR:tensor authority so every tensor value carries a real allocation-capacity and provenance witness - today TV-NEW-HOST records neither, which is the root defect - and compute mutators take the tensor value itself; (B) a new typed mutable span value carrying pointer and extent with a capacity role. A second registry over memory the tensor authority already owns is forbidden; candidate B is acceptable only if the design proves tensor extension cannot express the invariant. The chosen design then freezes: package-owned indexed access, no caller-supplied length trusted; its owner (TENSOR if A, likely package MAKI beside array.f if B); the migration order for GELU, the published matmul words, EMBED-ROWS, ADD!, and the LayerNorm wrappers onto it; and the adjacent write-effect checker gap (fail-closed-before-write) recorded as its own capability entry. Every new public compute mutator waits on this design; consolidation moves of existing surface (the ADD! leaf) proceed because they add no new unsafe API. Owner: design document reviewed jointly by both orchestrators before any implementation dot is minted. Dependencies: none. Acceptance: both orchestrators accept the frozen type, owner, and migration order; each migration step is a named sub-30-minute leaf; the design names what the checker enforces at each step and what remains runtime-thrown. Forbidden: implementation in this leaf, raw-shape compromises, per-word local guards presented as the fix.
