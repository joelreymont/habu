Problem: src/core/checker.f LAYOUT-BLOCK? rejects every logical layout paired with an ordinary generic value variable unless a whole-bundle transport or storage-introduction window is armed. As a result, closed non-linear one-cell values cannot instantiate ordinary generics: OPTION:SOME and RESULT:OK/ERR reject a payloadless ENUM or one-cell STRUCTURE with expected a and the concrete family as actual, and a generic ( a -- a ) identity rejects the same values. The layout is one physical cell and non-linear, so this blanket rejection is stricter than the value invariant; wide, hidden, open, possibly-linear, pointer-element, and raw-storage cases must remain closed. Exact implementation: src/core/checker.f owns private LAYOUT-W1? ( n -- bool ), true exactly when a term resolves to a logical T-PARAM that is resolved, PARAM>HID zero, closed, non-linear (LAYOUT-MAYBE-LINEAR? false), and T-WIDTH exactly one. Both PUSH-LOGICAL and the new private LAYOUT-CELL-BIND? ( n n -- bool ), consulted by LAYOUT-BLOCK?, use that single predicate: PUSH-LOGICAL keeps a LAYOUT-W1? layout logical instead of expanding it to hidden physical fields, while zero-width, wide, and closed-linear layouts still expand; LAYOUT-CELL-BIND? permits a pair only when CUR-STRICT is zero, exactly one side is a type variable, and the other satisfies LAYOUT-W1?. Effect variables never bind hidden terms. The shared invariant has two further mandatory checker callers: LOC-FAM-ANN keeps LAYOUT-W1? annotations logical instead of minting hidden slot zero, and MATCH-SCRUT? accepts and pops a same-family logical width-one scrutinee, setting MTCH-TAGT to it. All other layouts retain their current hidden paths. Existing RAW-BLOCK? remains authoritative for raw-storage variables. Same-family parameter pairing and existing whole-bundle transport remain unchanged. Forbidden: changing CON-OK?, pointer strictness, TFAM-CTOR-STEP?, constructor names or effects, global var-to-layout admission, family/name special cases, runtime guards, casts, trust, compatibility behavior, or weakening wide/open/linear rejection. Acceptance: production fixtures in test/type-ctor-suite.f certify and runtime-round-trip a local payloadless ENUM and one-cell STRUCTURE through OPTION:SOME, RESULT:OK, RESULT:ERR, MATCH, and a generic identity; payloads and tags return exactly. Existing or added mutation anchors keep zero-cell and two-cell layouts, hidden fields, open or possibly-linear layouts, foreign families, raw-storage minting, and ptr a versus ptr <layout> in both directions rejected.
