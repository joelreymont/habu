Problem: src/arch/arm64/disasm.f's DIS1, which tools/code-dump.f (through tools/code-dump-arm.f) and tools/imagedisasm.f use, prints ? for an instruction it has no row for, and decoded operands print as bare numbers with no register names or branch targets. On the installed hb, `hb --load tools/code-dump.f -- ': FIB ( n -- n ) dup 2 < if exit then dup 1- recurse swap 2 - recurse + ;' FIB` prints 24 instructions, two of them `? F85F8269` (ldur x9, [x19, #-8]); str/ldr pre- and post-index, bl and b.cond decode, as `str-pre 30 31 -16` and `bl -44`. llvm-objdump decodes them all. Acceptance: every encoding src/arch/arm64/asm.f can produce decodes to its mnemonic, registers and immediates, one line per instruction with branch targets as offsets; a native-suite row decodes each encoder's output and compares it with what was encoded (the encoder is the oracle, not llvm). Verify: the row; tools/code-dump.f on FIB, SUMSQ and MIX matches llvm-objdump. Claim: unassigned.

Acceptance case 2026-11-10 (bob; merged from habu-teach-the-arm64-d98eec15 "Teach the ARM64 disassembler the unscaled forms", one cause with this dot): src/arch/arm64/disasm.f prints '?' for Ldur and Stur, which are now ordinary instructions in emitted code: since habu-place-the-data-9f128e58 a routine stands its data-stack pointer where the fewest adjustments are needed, so an access one cell UNDER the pointer is the common case and it is encoded in the unscaled signed form. A code dump is the first tool anyone reaches for on a codegen crash, and it now renders the two instructions that carry every argument and every result of a compiled word as a question mark. The decode itself is four lines - mask $FFC00000 against $F8400000 and $F8000000, offset is a signed nine-bit field at bit twelve - and was written and then withdrawn from the placement commit for one reason: tools/package-diff-lint.f reported every definition the wholly global disasm.f changes (E-PACKAGE-OWNERSHIP). That lint is deleted. disasm.f is still a wholly global file, loaded by tools/code-dump-arm.f, tools/imagedisasm.f and tools/imagedisasm-test.f, which name DIS1 and DISASM bare. So the work is: add the two forms with a test that decodes a known word each way. Owner: src/arch/arm64/disasm.f.
