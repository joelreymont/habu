File: src/runtime/primitives/io.zig (format function)

Issue: format primitive implements only basic directives. Many CL format directives are missing.

Working directives:
- ~A (aesthetic)
- ~S (standard/readable)
- ~D (decimal)
- ~% (newline)

Missing directives:
- ~& (fresh-line)
- ~C (character)
- ~X (hexadecimal)
- ~O (octal)
- ~B (binary)
- ~F (float fixed)
- ~E (float exponential)
- ~$ (monetary)
- ~{ ~} (iteration)
- ~[ ~] (conditional)
- ~< ~> (justification)
- ~* (argument jumping)
- ~? (recursive format)

Priority missing:
1. ~& (fresh-line) - high priority, commonly used
2. ~C (character) - medium
3. ~X ~O ~B (numeric bases) - medium
4. ~F ~E (float formatting) - low (if floats work)

Fix: Extend format primitive in io.zig to handle more directives. Start with ~& and ~C.
