Problem: a direct call binds a fresh name on the callee's plain inputs to the argument's identity (src/core/checker.f E-AK-BIND, ~10454) and mints only the rest, but executing a ticked word mints every fresh name at the tick (TICK-QUOT / EFF-QUOT), inputs included, so a sound program is refused: with defer RR-OWN ( -- matrix<space-global,fresh-region-a,f32,f32> ) and defer RR-MFRESH ( matrix<space-global,fresh-region-b,f32,f32> -- matrix<space-global,fresh-region-b,f32,f32> ), ': X1A ( -- ) RR-OWN ['] RR-MFRESH execute drop ;' is refused ('expected matrix<...fresh-region-b-a...> actual matrix<...fresh-region-a-b...>') on master d411bc5b, lane qmint and its folds, while the direct ': X1D ( -- ) RR-OWN dup RR-MFRESH swap RR-MFRESH RR-UONE ;' is admitted. Found by lane qmint fold 2 (probes /tmp/jerry-qmint-tmp/pr/x1v.f). Acceptance: a ticked word's fresh name on a plain input is a variable at every occurrence, as E-AK-BIND makes it at a direct call, so X1A and 'RR-OWN dup ['] RR-MFRESH execute swap ['] RR-MFRESH execute RR-UONE' are admitted and every rigid-region row keeps its answer; a rigid-region row shows X1A admitted (refused on master). Files: src/core/checker.f (TICK-QUOT, EFF-QUOT instantiation; share E-AK-BIND's rule, no second copy), test/rigid-region-suite.f, docs/forth.md 'Rigid host-allocation identity domains'. Verify: rows rigid-region, linear. Depends: lane qmint landed (habu-mint-a-quotation-060811e6). Claim: unassigned.

Same class (qmint fold 1-2 re-review, probe /tmp/jerry-qmint-rv3-tmp/pr/y3.f): an executed tick or literal shares its effect's value variables across executions, while a direct call instantiates them per call (E-I-TV); QUOT-INST/QUOT-APPLY-INST share them by design (checker.f comment ~3640). With IDX ( x -- x ): V1T ['] IDX dup 1 swap execute drop RR-OWN swap execute drop is refused on master and lane qmint (expected n, actual matrix); the direct 1 IDX drop RR-OWN IDX drop is admitted. Also refused though sound: Y5TM, Y8M (y2.f). The fix is one design: a quotation's type is instantiated per execution as a direct call instantiates a callee's effect, X1's fresh inputs included; settle which variables are the quotation's own (not the enclosing definition's) before coding.

qmint fold 3 makes two sound programs refused at the second execute (/tmp/jerry-qmint-tmp/f3/y2b.f): Y8SEP `[: RR-OWN swap RR-APPX ;] dup [: ;] swap execute RR-MFRESH drop [: ;] swap execute RR-MFRESH drop` and Y5SEP (the same through `['] RR-GIVEX`). The quotation's quantifier x is bound by the first execution to its minted identity, and the second execution's new identity does not match it. Admitted before only because no identity was renewed, which also admitted the unsound Y8 (both executions into RR-UONE). Without per-execution instantiation of a quotation's quantifiers no rule tells Y8 from Y8SEP; the checker refuses both until this dot lands, and this dot's fix must admit Y8SEP and Y5SEP again.
