Problem: HBR2 §3.1 keeps tree pages, records and chunks in fixed page pools addressed by generation-checked IDs; §3.4 requires checked u64 reference counts, an intrusive retirement queue, a reclaim step bounded by an edge budget, separate pools and quotas checked before reserving, under the §26.1 ceilings. lib/memory.f maps OS memory per call and has none of this, and the same RUNTIME source must later compile for wasm32. Acceptance: in package RT-POOL, fixed-slot pools, one per §3.4 class (immutable pages, transient transaction and build storage, job states, packets, emergency diagnostics), over tables of 64 KiB chunks from MEM:ALLOC-64K (lib/memory.f:264), one chunk at a time up to a named ceiling constant per §26.1 class, the emergency pool reserved whole at INIT, chunks never moved or freed before SHUTDOWN; the emergency pool closed to ordinary allocation; slot IDs are RT-HANDLE handles and never expose a raw pointer; a checked u64 refcount whose overflow is fatal to the candidate and never wraps; the last release links the object onto a retirement queue through its own header, allocating nothing; RECLAIM-STEP visits at most a declared edge budget through a per-schema child enumerator, decrements the children, bumps the slot generation and returns the slot; quotas are checked before a reserve, and a refused reserve answers RecoverableOOM and changes nothing; a growth refused by ceiling or E-MEM-MAP answers RecoverableOOM as a status; byte ledgers charge an allocation once however many references hold it (§26.1). Files: lib/runtime/pool.f (new, package RT-POOL; mints E-RT-POOL-FIRST/LAST -9520..-9529 in its owning file), lib/errors.f (one comment line), lib/runtime/pool-test.f (new), test/gate-stdlib-cases.f. Verify: bin/hb --load lib/runtime/pool-test.f: releasing the root of a 100,000-object chain reclaims it over many RECLAIM-STEP calls, none over its edge budget and none recursing; a stale slot ID, a double release and a refcount overflow are each refused by code; a reserve over quota leaves every ledger unchanged; bin/hb --load test/run.f.
