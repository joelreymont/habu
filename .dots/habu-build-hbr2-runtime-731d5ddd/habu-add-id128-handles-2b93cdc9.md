Problem: every RUNTIME and UI record names persistent identities as opaque 128-bit values and temporary resources as generation-checked handles (HBR2 §2.1), and classifies every failure by the §5.2 error classes; Habu has none of them, and a bare cell would let a document ID, a handle and a pointer interchange, which §2.1 forbids. Acceptance: in packages RT-ID (Id128, ErrorClass) and RT-HANDLE (Handle, handle tables), Id128 as a 16-byte value (constructor from a byte span, lexicographic compare, equality, zero test, no route to or from n outside its package); Handle (slot u32, generation u32), null when both are zero and refused when only one is; each token is a public DEFTYPE whose generated converters are retired with `undefine` and redeclared as private CAST: words (D13), so a route from n exists only inside the package; a handle table owned by one context and allocator kind that issues handles, refuses a stale or foreign one, retires a slot whose generation is exhausted and never wraps (§2.1); a never-reused u64 counter for ComponentInstanceId and PlacementId whose exhaustion throws instead of wrapping; the §5.2 ErrorClass enumeration, keeping the full i64 throw code beside the class; each package's error decade minted in its owning file and noted by one comment line in lib/errors.f (forth-card §6). Tables cover the Habu-allocated rows of §2.1; host-allocated rows stay with the host. Files: lib/runtime/id.f (new, package RT-ID; mints E-RT-ID-FIRST/LAST -9500..-9509 in its owning file), lib/runtime/handle.f (new, package RT-HANDLE; mints E-RT-HANDLE-FIRST/LAST -9510..-9519 in its owning file), lib/runtime/id-test.f (new), lib/errors.f (one comment line per package), test/gate-stdlib-cases.f. Verify: bin/hb --load lib/runtime/id-test.f: an Id128 passed where a Handle is expected is a checker refusal; `RT-ID:>ID128` from another package is E-UNDEFINED; a stale handle, a half-null handle and an exhausted generation are each refused by code; bin/hb --load test/run.f. Depends: habu-land-hbr2-as-9b56de1a. Ownership: lib/runtime/id.f, lib/runtime/handle.f. Lane: tim. Claim: unassigned.
