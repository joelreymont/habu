Problem: a type's generated words are rendered as source text that names engine words by spelling, and both the check (src/core/sumtype.f TDPLAN-PREFLIGHT :1342) and the compile (TDECL-ADDR-EVAL :2033, through the interpreter's FIND) look that spelling up through the declaring package's search order, so a package word of the same name captures it. Silently wrong: a package that defines `*` before a STRUCTURE gets an AT that answers another element (sumtype.f:2008 spells `* record-at`); `=` before an ENUM or SUMTYPE with DERIVE eq inverts EQ; `+` before DERIVE init makes a getter read the wrong field; `drop` before an ARENA makes NAME-NEW call the package's word. Refused: a package word named RECORD-AT or `swap` ('in pair-at: at record-at raw storage cell ... bad structure declaration'); Tender defines RECORD-AT in src/score.f:157 and tenderd/graph.f and must declare its structures first. Only `field-project` is closed, by a reserved-name refusal (src/habu/interpreter.f DEF-RESERVED? :1554, DEF-WALL :1558). A qualified spelling does not fix it: the checker gives intrinsic identity per bound symbol and none to a qualified token (src/core/checker.f TOK-IDENTITY :18652, SPELLED-STEP? :22722). Generators that name engine words: STRUCTURE DERIVE addr (sumtype.f:1994, 2008), DERIVE tag/eq/hash and init (sumtype.f), src/core/structures.f +FIELD, src/lib/arena.f ARENA, src/lib/heap.f HEAP, src/core/layout-buffer.f LBUF-SOURCE :126 and LDEFER-SOURCE :386, src/lib/fsm.f FSM:DEFINE, src/lib/ffi-abi.f FUNCTION:. The generated text must still resolve in the package: its own family and field types, private generated names, FSM user words, MATCH variant names. Nothing binds past the search order today without a reserved name: the own-package spelling `P:*` falls through to the global word when P has no public `*` (src/habu/habu1.f:5899-5900), but a public word still captures it and a qualified token has no identity, so `P:record-at` and `P:swap` over a sum value are refused. Reproducers: package P private 8 constant RECORD-AT STRUCTURE pair DERIVE addr FIELD a n FIELD b n ;STRUCTURE ;package (refused); the same with `: * + ;` in place of the constant (loads, P-PAIR:AT answers the wrong element).
Acceptance: a generated definition binds the engine words its text names whatever the declaring package defines; each case above, as a test, answers right; no name is reserved for it.
Depends: none.
