Measured 2026-09-18 (rule lane): the acceptance above is not expressible as written. src/core/structures.f PTR-FIELD: generates ': NAME ( ptr a -- ptr ptr b ) <off> ptr-field ;' with a FREE pointee by design (there is no nominal record type in the language; BEGIN-STRUCTURE publishes only a size constant), and ptr-field's own row ( ptr a n -- ptr ptr b ) with b free is the loophole: both ': F ( ptr n -- ptr ptr u8 ) 0 ptr-field ;' and ': F ( ptr a -- ptr ptr u8 ) 0 ptr-field ;' launder an integer stored in a raw cell (measured on a rule engine), while the bare ': G ( ptr a -- ptr ptr u8 ) ;' is already refused with E-NONPARAMETRIC-EFFECT. Refusing only a scalar base pointee closes one fixture and leaves the one-character variant open; requiring a pointer-typed base pointee refuses essentially all ~180 call sites. Candidate rule (not yet designed): at the call, a pointer whose pointee is RAW may not enter a row that manufactures a pointer not derived from that pointee (a per-row 'manufactures a pointer' property checked when a RAW pointee binds), which refuses both launders and leaves ( ptr a -- ptr a ) accessors alone; its cost is a caller cascade over every record with a pointer field kept in create'd raw storage (src/lib/vector.f, src/lib/serial-xmodem.f SOURCE-FIELD/OUTPUT-FIELD, src/lib/byte-buffer.f DATA-FIELD, src/lib/db/pq.f, tools/lint/text.f LINT-SLAB:BUF-FIELD, tools/build-fixpoint.f BF-PTR-U8-FIELD), unmeasured. Root cause shared with habu-refuse-a-scalar-030be3ad: without a nominal record type, a record mixing a pointer field and scalar fields is expressed by casting one through ptr-field or through byte-view/cell-view; closing both holes needs a record facility (a campaign-level design). The rule landed without this hole closed; the LAUNDER fixture sits in test/typed-storage-structural-test.f SECTION-RAW-IS-VACUOUS as a documented-open row naming this dot.
Design landed 2026-09-18 (src/core/structure-decl.f header, on the line): this rule is the ptr-field narrowing, MD-FIELD-BASE-KIND (the next free MD- code when it lands; MD-UNDERFLOW took 28 on 2026-09-18) in the E-RAW-CELL-PTR family, reason 'ptr-field: base is <kind>, not a declared pointer cell' where <kind> names a parameter, a scalar-pointee cell or a raw cell, repair class declare_record_field; ptr-field then admits only a declared pointer cell (PTR-VARIABLE, PERSISTED-PTR-VARIABLE, PTR-U8-TABLE, PERSISTED-PTR-U8-TABLE-VARIABLE, TYPED-VARIABLE NAME ptr t, TYPED-BUFFER, a reserved engine cell, or an element of one of those). It lands last, after every cast site is migrated, because it refuses about 75 sites at once.
