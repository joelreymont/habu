DIAGNOSIS, 2026-08-04, read off both emitted streams instruction by instruction. The engine's T-RES-WALK is nine instructions (sub sp #16 / str x30 / bl TV-NEXT? / sub x19 #8 / ldr x9 [x19] / cbz x9 -> exit / b -> the bl / ldr x30 / add sp #16) and the chain's T-RES-WALK-N is nineteen. Eight are common and the chain's `sub x19,#16` answers the engine's `sub x19,#8`, so the ten extra are exactly: offset 8 `sub x19,#8` (DTAKE), offset 12 `ldr x0,[x19]` (entry DLOAD of the argument), offset 16 `str x0,[x19]` (the call's DSTORE of that same argument into the slot it came out of), offset 20 `add x19,#8` (the call's DBYTES), offset 32 `ldr x0,[x19]` (DLOAD of the call's first result), offset 44 `b -> 56` (the two-way branch's trailing branch, because the loop body block is not laid out next), offset 48 `orr x1,xzr,x0` (the edge copy into the after-loop block's argument, uncoalesced because the exit stub sits between the header and the body in the linear order, so the hull intervals overlap where the real live ranges do not), offset 52 `b -> 60` (the stub's branch, because the after-loop block is not laid out next), offset 60 `str x1,[x19]` (the return's DSTORE into the slot the value already occupies) and offset 64 `add x19,#8` (DPUBLISH). They fall into three independent mechanisms and NO ONE OF THEM REACHES 36 BYTES ALONE. Five instructions (12, 16, 32, 48, 60) are a value moving in and out of a data-stack slot it never leaves: habu-keep-a-pass-8025401f, 76 -> 56. Three (8, 20, 64) are pointer moves the routine does not need: habu-place-the-data-9f128e58, 56 -> 44. Two (44, 52) are trailing branches a chosen block order would delete: habu-order-blocks-to-f6d89653, 44 -> 36. The arithmetic is exact and each mechanism is general - none is about this row - so this dot is the sum of those three and is blocked on all three. What was refused: a row-targeted special case, and shipping any one mechanism half-built, since the independent allocation validator (src/compiler/native/regalloc-verify.f VDSTACK-CK and VCALL-SITE) has to re-derive each relaxation for itself and a partial relaxation there is exactly the class of bug it exists to catch.
