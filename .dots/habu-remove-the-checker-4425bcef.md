Problem: the public engine words set-check, check@ and set-preflight still write and read HOOK-CELL (src/habu/habu1.f:3471 BSETCHECK, :3571 BSETPREFLIGHT, :1364 BCHECKFETCH; kernel-x64.f:3203 SET-CHECK-BODY), a switch any program holds, though the compile paths no longer call the cell: they call CHECK:DEFINITION directly (src/compiler/native/definition.f:137, src/habu/interpreter.f:2096), and the cell is read only as a nonzero test (src/habu/habu2.f:520 in FIND-ACTIVE). On the installed hb, '0 set-check' before ': BAD ( -- n ) dup ;' is refused at 'dup', rc 70 ('input underflow: the call takes more cells than the definition's declared inputs leave (needs 1, has 0)'; 'compiler: cannot compile BAD at dup'). set-check appears in 12 files under src, tools and test (44 lines), 10 of them engine sources (src/core render.f checker.f structure-make.f check-hook.f; src/habu prims.f xref.f habu1.f layout.f kernel-x64.f; src/os/linux-x86-64/target-layout.f). The switch costs suspend cells (layout.f:805 SUSP-HOOK-CELL, :806 SUSP-PREFLIGHT-CELL), installer guards, the switch's tests (test/x86-64-kernel-engine.f:203-225), and checker rules for cells left in a window (checker.f:5151 MD-TOP-UNKNOWN). src/core/check-hook.f is package CHECK (line 5); its TRUSTED: INSTALL (:458) installs the hook and preflight through set-preflight and set-check and runs at :474; TOP-SITE, TOP-SITE-PATH$ and LINE-AT are CHECK words in checker.f (:24358, :19434, :24346). Joel 2026-11-02 chose 'Remove the switch'. Acceptance: after the kernel loads, every definition is checked and no word turns checking off; only kernel files, loaded before the checker exists, compile unchecked; any cell the machine-code compiler still needs is set once, private and stripped; set-check, check@ and set-preflight are gone; tests that switch it off are rewritten or deleted; the replacement words' names go to Joel with the design's word list. Files: per the design. Verify: full suite, generation convergence, the recovery check (tools/seed.f, docs/bootstrap.md "Recovery"), which replaces the no-binary seed mirror. Depends: a design with a census of the switch's sites, test sites planned by class only. Joel's rulings (2026-11-02): package CHECK, entry CHECK:DEFINITION ( ptr u8 n -- n ); set-top-check goes too; no owner-record slot for engine-origin: the checker sets a flag on the definition, and the cast observer (src/core/checker-owner-abi.f:11 CAST-OFF) is reviewed for the same change; SRCLOC:LINE and SRCLOC:COLUMN ( ptr u8 -- n bool ) and SRCLOC:PATH$ ( -- ptr u8 n ) replace LINE-AT, TOP-SITE and TOP-SITE-PATH$, and tools/check.f's run file keeps columns so top-level errors print one.
