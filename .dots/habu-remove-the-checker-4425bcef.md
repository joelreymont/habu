Problem: the machine-code compiler calls whatever xt sits in HOOK-CELL (src/habu/habu2.f HOOK-CELL reads; habu1.f BSETCHECK, BSETPREFLIGHT; kernel-x64.f SET-CHECK-BODY), and the public engine words set-check, check@ and set-preflight make that cell a switch any program holds: on the installed hb, '0 set-check' before ': BAD ( -- n ) dup ;' lets BAD compile and run (exit 70, 'interpret stack underdepth') where it is otherwise refused. set-check appears in 73 files (359 lines), 13 of them engine sources (src/core sumtype.f render.f top-row.f checker.f; src/habu window-rewind.f aot-capture.f kernel-x64.f habu1.f habu2.f xref.f layout.f aot-common.f; src/os/linux-x86-64/target-layout.f). The switch costs suspend cells (layout.f SUSP-HOOK-CELL, SUSP-PREFLIGHT-CELL), installer guards, a hookless compile path (src/compiler/native/definition.f CHECK-HOOKLESS), HOOK-CELL tests in src/habu/definers.f, and checker rules for cells left in a window (render.f MD-TOP-UNKNOWN). The package LOWER-CERT-HOOK (src/core/check-hook.f; INSTALL, HOOK, TOP-SITE, TOP-SITE-PATH$, LINE-AT) is named for the mechanism. Joel 2026-11-02 (DECISIONS.md 'the checker's switch') chose 'Remove the switch'. Acceptance: after the kernel loads, every definition is checked and no word turns checking off; the typed interpret loop calls the checker as an ordinary word (docs/architecture.md 'Interpreter'); only kernel files, loaded before the checker exists, compile unchecked; any cell the machine-code compiler still needs is set once, private and stripped; set-check, check@, set-preflight and LOWER-CERT-HOOK are gone; each engine file's window gets its checked form; tests that switch it off are rewritten or deleted; the replacement words' names go to Joel with the design's word list. Files: per the design. Verify: full suite, generation convergence, no-binary recovery check (seed mirror). Depends: the design, .jj-ws.noindex/carl-dots/.out/carl-file/design-switch.md (Opus Plan, 2026-11-02; census /tmp/carl-switch/census.md), test sites planned by class only. Lead calls (carl, 2026-11-02): `seed-ndict!` keeps its reach, since a rewind to the bare kernel discards the checker with everything after it and rebuilds the engine, which is not a switch; `set-top-check` goes in this work, not as an option. Joel's rulings (DECISIONS 'the checker's switch', 2026-11-02): package CHECK, entry CHECK:DEFINITION ( ptr u8 n -- n ); discard-check and set-top-check go too; no owner-record slot for engine-origin: the checker sets a flag on the definition, and the cast and export observers (CHECKER-OWNER-EXT CAST-OFF, EXPORT-ACCEPT-OFF; src/habu/engine-origin-checked.f INSTALL) are reviewed for the same change; SRCLOC:LINE and SRCLOC:COLUMN ( ptr u8 -- n bool ) and SRCLOC:PATH$ ( -- ptr u8 n ) replace LINE-AT, TOP-SITE and TOP-SITE-PATH$, and tools/check.f's run file keeps columns so top-level errors print one. Next: a census of what engine-origin does with each observation (definition, cast, export) and whether a flag on the record replaces it, then the design's step 5 rewritten. Ownership: carl.
