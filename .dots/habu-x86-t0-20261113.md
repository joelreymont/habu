The SPARQL rewrite needs a runnable Habu compiler on Linux x86-64. Joel
authorized a separate `x86` branch and requires T0 for x86 compilation.

Use the existing x86 assembler, kernel and T0 emitter with the current linker.
Share kernel-object framing and ELF metadata with ARM64. Keep target instruction
patches and startup code in their architecture directories. Do not revive the
retired capture pipeline or substitute T1 for an x86 build.

The branch currently contains uncompiled source changes. Kernel completion,
an executable T0 build, cold/warm equality, and native self-build remain open.
The x86 linker initially retains the whole kernel; reachability pruning is not
part of the first runnable image.

Focused executable test: `test/compiler/x86-64-link-run.f`. It builds a source
program containing a quotation, calls and a data literal, executes it, and
compares the cold and warm image digests. Broader native and consumer gates
follow a working compiler.
