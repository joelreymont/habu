Current master architecture/bloat defect in new tools/lint/diff.f: the 949-line parser declares typed phase/form/event tags but stores every payload in more than 40 ambient variables. Section identity, old/new spans, event spans, hunk ranges, mode/hash facts, rename/copy pairs, similarity, and lifecycle flags are updated independently; RESET-SECTION clears them by hand. Public LINE/FINISH return only a nullary event kind, then SECTION-OLD$/NEW$/FORM/BODY?, HUNK-NEW-START, and CONTENT$ read the latest ambient payload after checking only that kind. A saved section token cannot identify its section after another section event, and the type surface cannot make incomplete rename pairs, conflicting add/delete flags, phase-with-wrong-payload, or stale accessor use unrepresentable. The input-lifetime contract is internally false too: the header says spans are borrowed until the next parser call, but HEAD/OLD/NEW retain caller pointers across many subsequent LINE calls before emitting a section. Reusing one line buffer corrupts metadata; tests hide it with stable literals or one immutable whole-diff buffer. There is also a truncation hole: EMPTY-HASH? at 356-359 treats any 7-to-40/64-character prefix of the SHA-1/SHA-256 empty blob as proof of empty content. A nonempty blob with the same abbreviated prefix followed by a truncated diff is accepted as an empty add/delete. Define STRUCTURE path-span and hunk-range, STRUCTURE section-event, payload-bearing ENUM event = none | section(section-event) | hunk(hunk-range) | add(span) | context(span) | delete(span), and payload-bearing parser phase whose meta/body/hunk variants carry exactly their legal state. Return the event payload directly and destructure it with MATCH; delete ambient EVENT-* payload cells, NEED-EVENT, type-specific accessors, independent paired booleans, and the manual mega-reset. Copy retained metadata transactionally into one bounded parser-owned arena, or consume offsets into an explicitly immutable whole-source owner; never retain arbitrary LINE buffer pointers. Event payload spans may borrow that stable owner until the documented next transition. Empty-body proof must use the authenticated full content identity/body-presence fact from the framed diff provider, never a collision-prone abbreviated prefix; raw line input lacking that proof stays incomplete/fails closed. Preserve other accepted/rejected jj syntax, finding behavior, error identity, path policy, hunk ordering/counts, form classification, and zero dynamic allocation. Add checker negatives for event/form/span/range swaps and absent variant payloads; transition/property tests for every metadata ordering, malformed pair, stale-event misuse boundary, a single mutable buffer overwritten before every LINE, retention-cap rollback, truncation, empty-prefix collision at every accepted abbreviation length and both hash families, overflow, spoofed headers, rename/copy/mode/binary cases, and every existing hostile path. Measure source definitions/lines, globals, dictionary-name/JIT/DATA/CODELEN, parser throughput, and both consumer gates; require substantial reduction with no compatibility aliases. The closed habu-lint-diff-share-486c2d86 keeps shared-parser behavioral ownership; serialize content-identity changes with habu-tools-frame-diff-e98f8a6a, while this dot owns representation and factoring.
