Measured by the stageb-design lane (2026-08-11), pays on every boot the gate already runs: the engine flips mprotect over the WHOLE 8MB REGION twice per definition (8.61us/call at 8MB vs 0.41us at 64KB, C microbench; 119ms of the chain load measured, ~10.6% of load cost and ~10% of every boot), and the (PROT-SPAN) store-range guard costs another ~9.2%. APPROACH CORRECTED 2026-08-11 (stageb lane, before any edit). This leaf first said "apply the LPROTREC narrow-flip precedent (habu2.f:2179) to the per-definition code-region toggle". That is wrong, and the precedent's own body says so: src/habu/habu1.f:2971-2980, the comment on LPROTREC, states that a stateless flip is sound ONLY where the target address is stable across the bracket, and names the CP-tracking emission and checker-call windows as the reason they "stay full-region". LPROTREC recomputes its window from x9 at both ends and x9 is a dict-record address that does not move; the code-region brackets emit between open and close, so a stateless narrow flip would close a different window than it opened and leave RW pages behind - weakening the very invariant this leaf's acceptance protects. The correct shape, ruled 2026-08-11: FIXED BASE, MONOTONE END. DBASE is stable across every bracket so it stays the base (satisfying the comment's own stability condition), and only the top moves - one way, because CP only advances inside a bracket (LCEMIT is str/add x28,#4, so a write never runs ahead of CP by more than one word). open = mprotect(DBASE, ceil_page(CP+extent), RW); close = mprotect(DBASE, ceil_page(CP+extent), RX) with CP_close >= CP_open, so the closed range CONTAINS the opened range and no page is orphaned. The extent is the caller's argument, not a constant in the body. Also measure whether the (PROT-SPAN) guard can cheapen without weakening (it is a guard - do not delete it; make it cost what it needs to cost). Acceptance: boot wall time drops measurably (baseline 0.40s, mprotect share ~40ms + guard share), full gate green, fixpoint byte-stable x2, the protection INVARIANT unchanged (a store outside the open span still refuses - keep the negative test).
