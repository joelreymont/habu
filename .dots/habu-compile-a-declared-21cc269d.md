Problem: the language lets a source signature declare return-stack cells (`: RC1 ( | n -- | n ) r> drop 0 >r ;`; docs/effects.md "The two return-stack conventions", and the sealing paragraph lets `r>` reach cells "declared after `|`"). The checker certifies it and tier 0 runs it, but tier 1 never compiled it: a declared return input is E-NELAB-UNDER -8304 (elaborate.f OPEN-BLOCK starts the return vector empty), a declared return output E-NELAB-JOIN -8503 (EMIT-RETURN), and a call to such a word E-HIR-UNMODELED -8286 (hir-word.f:939, :991; test/compiler/native-rstack.f NRS-Z3). Compiling it would need a physical return-stack transfer at entry, at return and at every call site in every backend, plus value grouping on the return vector (measured: ~/.cache/tmp/carl-rsin/handoff.md). No word outside test/ declares a return-stack cell: ~/.cache/tmp/carl-rsin/census.txt finds 10 test definitions in 5 files (test/cast-negative-suite.f:87 and the src/ hits are comments; it reads only colon-style heads, so the checker rule itself is the full census). Standard Forth forbids the form (ANS 3.2.3.3: a program may not read return-stack values it did not place there with `>R`).
Ruling: no signature written in source declares a return-stack cell. A definition (`:`, `TRUSTED:`, a quotation literal, a does> clause) reads only return-stack cells it pushed itself; a written `|` clause carries only a row variable kept unchanged (`( R n | S -- R | S )`, `[ in -- out | U -- U ]`). Quotation types in source signatures follow the same rule. Primitive effect rows (`>r`, `r>`, `2>r`, loop words) keep their return-stack cells.
Acceptance: the checker refuses a source signature that declares a return-stack cell on either side, at the declaration, at every tier, with one diagnostic naming the fix (an existing code if one fits; repair class fix_return_stack), and the Gforth host follows through the shared checker. rs1 and rs2 (~/.cache/tmp/carl-judge/rs/) and a quotation-type case are rejected programs in a tier-1 E2E test beside their tier-0 result. Every definition the rule refuses is converted: each test keeps the behavior it protects (ownership or staleness of a value parked on the return stack, the effect-read API, AOT payloads) inside one definition, or is deleted where the cross-word form was its only subject. Tier-1 code that exists only to refuse a call to a word whose rows move the return stack is deleted once the checker rule makes it unreachable, NRS-Z3 with it; the elaborator's own invariants stay. docs/effects.md (both conventions and the sealing paragraph), docs/forth.md "Rules learned by refusal" and docs/forth-card.md state the rule and the measured refusal. A tier-1 load of test/c2-owner-producer-refusals.f passes the converted REPLACE-R-OWNER.
Files: src/core/checker.f (signature declaration), src/compiler/native/hir-word.f, the test files the rule refuses, test/compiler/native-rstack.f, a tier-1 test, docs/effects.md, docs/forth.md, docs/forth-card.md, lib/errors.f only for a new code.
Verify: native build per docs/gate.md; the new test and each converted file; `bin/hb --load test/run.f`; two-generation build converges; `bin/hb --load tools/error-code-lint.f`.
