Why: device execution needs immutable bounded rows without receiving cache mutation authority. Result: DESCRIBE-BATCH ( KV:cache KV:batch -- KV:describe-result ) copies provisional lengths, device base and extent, layer layout, and block-table rows into the cache-owned fixed descriptor area established at cache construction, then returns described(cache,ready,count) or refused(cache,batch,describe-error). ready is the sole linear owner of that exact cache identity, session generation, descriptor generation, count, and private storage until cancellation or finalization. ROW ( KV:ready CAD-NUM:item-index -- KV:row-result ) returns row(ready,desc) or refused(ready,desc-error); MATCH-DESC ( KV:ready KV:desc -- KV:desc-match-result ) returns matched(ready,desc) only when the immutable owner-constructed row still equals the canonical provisional row for that ready. INFER authenticates each desc, then the active model arm consumes it to prepare ordinary device-operation arguments; DEVRT receives no KV value. No raw descriptor pointer or mutable span crosses the package. Owner: descriptor schema, private fixed storage, immutable row mint and match, and batch-to-ready transition only. Dependency: add provisional KV row. Production red: no immutable multi-row descriptor can cross from KV to the model arm. Acceptance: unique, boundary, layer, and copy-on-write rows describe deterministically; empty, stale, arithmetic, wrong-ready, cross-cache, cross-session, post-describe internal mutation, and descriptor substitution cases reject before the first enqueue without changing committed state; model arms receive only matching immutable rows and DEVRT remains KV-blind. Forbidden: caller descriptor storage, raw pointer, DEVRT KV input, cancellation, launch, completion, commit, public constructor, compatibility, metric, or lint. Smallest owning check: real DESCRIBE-BATCH, ROW, and MATCH-DESC exact, mutation, and substitution cases in maki/infer/kv-cache-test.f; the later RUN-ROWS owning check repeats the binding through first enqueue. Claim: unassigned.
