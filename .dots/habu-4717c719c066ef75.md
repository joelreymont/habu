Implement sequence copying functions.
Location: stdlib.habu
Functions:
  (copy-list list) - shallow copy, shares structure with tail
  (copy-alist alist) - copy with new cons cells for pairs
  (copy-tree tree) - deep copy of cons tree
  (copy-seq sequence) - copy any sequence
Examples:
  (copy-list '(a b c)) => (a b c) ; new cons cells
  (copy-tree '((a b) (c d))) ; deep copy
