Problem (read, not run; type-states design 2026-11-11): the linker's spelled-name scan cuts a name only at white space, ':' and '"' (src/habu/linker.f CUT? :1029), so a part that writes 'box<turn>' spells no 'turn'; whether the declaration of turn is tracked for that part another way was not found. 'TYPED-BUFFER BT box<turn>' bakes the width as a number, so a missed dependency is a warm build that differs from a cold one after turn's layout changes. Acceptance: a three-file reproducer shows warm equals cold after the edit, with the edge that carries the dependency named, or the miss is root-caused and fixed with a test. Files: src/habu/linker.f. Verify: the reproducer cold and warm. Depends: none. Ownership: carl. Claim: agent=carl workspace=.jj-ws.noindex/carl-tydep (fix, brief .out/briefs/fix-spelled-type-arguments.md).

Reproduced (hunt 2026-11-11, ~/.cache/tmp/carl-tydep p/ and run2.txt, installed 6062e143): a.f declares `turn` and `box<a>`; b.f `4 TYPED-BUFFER BT box<turn>`, d.f `: W ( box<turn> -- n )`, e.f `DYNAMIC-BUFFER DB box<turn>` name turn only inside brackets; c.f names it bare. After turn gains a field the warm build rewrites a.f, c.f and main and reuses b, d and e: warm prints `b 24 c 24 d 7 1 e 24`, cold `b 32 c 24 d 7 11 e 32`, binaries differ. Cause: SPELLED (src/habu/linker.f:1068-1082) cuts at blanks, ':' and '"' only, and the checker's family lookup (src/core/type-family.f TFAM-RESOLVE :5157, TFAM-FIND :5083) records nothing in the run log, so b.f's object has no FILES row for a.f.
Fix (lead): SPELLED also hits each run between '<', '>' and ',' inside a span, keeping every name it hits today, so the scan covers every way a type argument is written (effects, fields, definers, casts) without each checker path having to record. Extra names only add dependencies. Not chosen: the checker recording each resolved family argument (a path that forgets to record is a silent stale build). Not shown by the hunt: `A:box<A:turn>`, a type reached through a third record's field.
Found beside it, not dotted yet: a DERIVE addr field word of a generic STRUCTURE refuses a concrete instance (`: W1 ( ptr box<turn> -- ptr n ) BOX:REST ;` E-MISMATCH), which is Design 2's decision 1 in dot habu-give-an-arena-25a7d3cc.
