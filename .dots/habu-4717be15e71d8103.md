Location: stdlib.habu (macro) + runtime support
Syntax:
  (define-condition name (parent-types*) 
    ((slot-name :initarg :kw :reader reader-fn)*)

  (define-condition file-error (error) 
    ((pathname :initarg :pathname :reader file-error-pathname))
