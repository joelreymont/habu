Problem: the checker keeps a second dictionary beside the engine's. Its symbol table (src/core/checker.f:6819-7365: SYM-FIND, SYM-INTERN, case folding, SYM-GROW, the HIDX hash index, scope retirement) maps the engine's records by package, visibility and name (CHECKER-RECORD-SYM), and the checker mirrors the engine's scope: its own copy of the used package names (CK-USE-NAMES, three writers) and a re-probe of every used package on a using refusal (CK-USED-MARK :12519) after scope-find already answered. Two undo systems run in parallel: a checker frame saves 24 marks (RBF-SAVE-INTO :23929) and rewinds SYM-N, the string pool and the index beside the engine's ndict! rollback. Name keys drift: the global publish-xt and producer-xt rows hold active effects for words the engine holds only in package wordlists.
Measured (whitebox engine, arm64; ~/.cache/tmp/heron-arm64/evidence/sym-on-record/report.md): 20622 of 20775 boot symbols (99.3%) map one-to-one to a record in their own wordlist, and every symbol library code adds does. The rest: 15 keyword axioms with no record (s" ." ['] char >r r> ...), 71 owner rows (PPRIM:/EPPRIM:, one record with several typed views or packages with no namespace row), rows recorded outside the overlay (CHECK! by hand, candidate and plain scopes make a symbol with no record; the neutral scope already publishes a codeless record), marks (describe a wordlist), and identities that cross images or checker owners (the unit checker section, TRANSFER-SYMBOL, checker-owner-abi.f).
Ruling (Joel, 2026-10-08): a word's type hangs off the engine's own dictionary record; there is one dictionary.
Acceptance: per-word checker data (effect, control and defer heads, primitive entry, variant constructor, memo cells, signature, unsafe and parsing-immediate entries) is keyed by record index, held with the record (a record cell or a table indexed by record; packing into the name-length bits is not a home) and cleared where the engine writes or discards a record, on arm64 and x86-64, and captured with the image; every scope that records rows publishes a record; the 15 keyword axioms sit in a table keyed by spelling; marks become per-wordlist data; package and visibility come from the record's wordlist; the used names and an ambiguous name's candidates come from the engine's state and lookup. Deleted: the symbol table and HIDX (52 words), the name bridges and using mirror (31 words), SYM-N/SYM-STR-U in the rollback frame, SYMS-RETIRE-SOURCE. The unit section and owner ABI resolve names to records at their boundary.
Order: the owner rows go first (habu-move-engine-internal-fc2ba551), then every recording scope publishes a record, then the re-key.
Files: src/core/checker.f, src/core/type-family.f, src/core/sumtype.f, src/habu/layout.f, src/habu/habu2.f, src/habu/kernel-x64.f, src/core/checker-owner-abi.f, src/core/render.f.
Verify: full suite on the built hb; the using refusal rows (test/using-test.f) unchanged in output; multi-generation convergence (capture changes).
