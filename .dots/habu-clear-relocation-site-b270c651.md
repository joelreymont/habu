title: Clear relocation site maps when CP rewinds
status: open
priority: 2

created-at: "2026-07-30T11:07:34.287473+02:00"

Both snapshot relocation site maps - SNAP-RELOC:CALLMAP-OFF (dot habu-relocate-snapshot-region-752042fe) and SNAP-RELOC:ADDRMAP-OFF (dot habu-relocate-persisted-region-47de06b9) - record one bit per four-byte word of the JIT region at the moment an instruction is created, and NOTHING clears those bits when the code pointer rewinds. A truncate-and-recompile (src/habu/hide.f HIDE-DEFS-FROM / FORGET-DEFS-FROM, which the native refresh and the snapshot build both use) moves CP back and lets different code be emitted over the same region words, so a bit recorded by the previous generation can survive over a word that is no longer a call and no longer a MOVZ/MOVK chain. Both relocation passes verify the shape of a recorded site before rewriting it - EMIT-CALLS checks the six BL opcode bits, EMIT-ADDRS masks all four words against W-MOVZ0/W-MOVK1/W-MOVK2/W-MOVK3 - so the consequence is a LOUD refusal (CALLMAP-RC 95 / ADDRMAP-RC 97, 'hb: snapshot call map mismatch' / 'hb: snapshot address map mismatch') on an image that is in fact fine, never a silent wild branch. It did not fire in any build, boot or test measured on 2026-07-30 (eight fixpoint rebuilds, three snapshot builds, 200 bare boots, test/snapshot-xt-cell-decl.f, tools/build-fixpoint-test.f), most likely because the deterministic fixpoint build re-emits chains and calls at the same offsets, but a user image that restores, forgets, and recompiles different source is not deterministic in that way. The structural invariant is that a recorded site is only valid while the instruction that created it is live, so a CP rewind invalidates every site at or above the new CP. The right fix is at the rewind chokepoint - clear both maps over [new CP, old CP) where CP is lowered (habu1.f BCPSET / the dictionary truncation words) - and NOT at the per-word emit path, which would put roughly eight instructions on the hot compile path for a rare event. Do not weaken either pass's shape check to hide the symptom: the check is what makes a genuine map/region disagreement fail closed. Acceptance: a regression that restores an image, truncates the dictionary below existing recorded sites, recompiles different source over them, writes a snapshot and restores it, and passes; plus a negative case proving a genuinely corrupt map still exits 95/97.
