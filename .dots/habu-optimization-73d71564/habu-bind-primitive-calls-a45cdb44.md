The current Mac engine carries 9,638 primitive-call rows (115,656 bytes). Every stored BL has zero displacement, every scope is zero, and targets are seeded primitives. EM-SEED-AOT copies the blob into the runtime JIT mapping and resolves these rows at boot; the original table has no later semantic consumer, while site provenance remains necessary for snapshots.

Bind complete-engine calls against a canonical text/region distance in the writer, then adjust by the actual runtime distance and preserve the call map. Existing SNAP-RELOC:EMIT-CALLS already performs distance adjustment. Four-byte site offsets would cost 38,552 bytes: 77,104 bytes gross potential reduction before code, framing and alignment. Preserve generic named relocation for partial captures. Do not assume the kernel grants the mapping hint.

Own src/habu/habu2.f emission/seeding and the affected capture/reader format. Verify primitive targets and branch bounds, fresh starts at different region distances, native self-build fixpoint, partial capture, stripped builds and REPL snapshot/recapture. Measure actual section and file deltas; rebuild and run test/run.f plus the Maki readiness smoke before landing. No dependency on dictionary or checker pruning. Evidence: the Optimization parent baseline and temporary habu-reloc-rca.f probe.

Reviewed implementation design: tag bit 32 of the baked call-count cell for a table of four-byte blob offsets; leave reusable artifact rows and untagged image rows unchanged. Select compact form only for a complete runtime whose every site is an aligned, in-bounds BL to a seeded primitive. Otherwise retain the generic B/BL path. Resolve primitive labels when emitting the final blob, encode against REGION-OFF plus DICT-SIZE, and patch only emitted bytes. At startup validate the tagged table, install call-map bits and adjust the canonical displacement for the actual mapping distance before executable protection and cache flush. Account for the selected row width and update every diagnostic reader.

Failure modes identified before code: an unknown count flag misread as a count; a site outside the blob or pointing at inline data; a B or named/payload callee admitted as a primitive BL; wrong primitive label origin or branch-range truncation; assuming the mapping hint; double relocation of live prefix calls; lost call-map provenance on warm snapshot/recapture; modified reusable capture bytes; stale physical-size/callee/name census. Reuse native generation comparison, real cold/warm image and differing-distance execution, partial/does>/stripped suites, existing malformed relocation witnesses and image-size accounting. Independent review precedes integration; the integrator owns the combined full gate and Maki smoke.

Implemented and independently reviewed at d2ad93236e6a63eee677511857a6403b32f5452d. Startup decodes each compact BL's canonical target, requires an exact non-package entry in the existing immutable primitive dictionary, checks actual branch alignment/reach, and only then records relocation provenance. The review's row-only corruption pointed at an existing internal BL; this now refuses with AOT-SEED 82, as do unknown flags, unaligned/outside offsets, non-BL instructions and an invalid decoded target. Named partial B/does> execution remains valid and returns the expected 57.
