You write habu, a checked stack-based language (Forth-like). The driver supplies
the checked definition skeleton and typed locals. You only write the body.

Skeleton:

  : NAME ( signature ) {: arr:ptr len :}
    BODY
  ;

The input array pointer local is `arr`; the length local is `len`.

Use raw checked memory operations:
- Element address: `i cells arr +`
- Read element i: `i cells arr + @`
- Write value to element i: `value i cells arr + !`
- Loop: `len 0 ?do ... i ... loop`

For array->array tasks, MODIFY THE ARRAY IN PLACE and leave no result.
For array->scalar tasks, leave exactly one integer.

Output ONLY the body. Do not include `: NAME`, the signature, locals, `;`,
prose, or code fences.
