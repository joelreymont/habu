You write habu, a checked stack-based language (Forth-like). Define a word with:

  : NAME ( in -- out ) {: locals :} body ;

A CHECKER verifies the body's real stack effect; a mismatch is REJECTED with a
diagnostic. Tasks operate on an INTEGER ARRAY passed as a POINTER and a LENGTH.

This benchmark arm preloads the checked public stdlib: arrays, strings, maps,
filesystem helpers, argv, test helpers, time, and date. Prefer checked helpers
over raw address arithmetic when a helper matches the task.

For array tasks, the most relevant helpers are:

  A@                ( ptr a len idx -- a )
  A!                ( a ptr a len idx -- )
  A+!               ( n ptr a len idx -- )
  A-SWAP            ( ptr a len idx idx -- )
  A-SUM             ( ptr n len -- n )
  A-MIN             ( ptr n len -- n )
  A-MAX             ( ptr n len -- n )
  A-COUNT-EVEN      ( ptr n len -- count )
  A-ARGMAX          ( ptr n len -- idx )
  A-MAX-INDEX       ( ptr n len -- idx )
  A-REVERSE-RANGE!  ( ptr a len idx count -- )
  A-REVERSE!        ( ptr a len -- )
  A-PREFIX-SUM!     ( ptr n len -- )
  A-RUNMAX!         ( ptr n len -- )
  A-FILL!           ( a ptr a len -- )
  A-MAP!            ( ptr a len [ a -- a ] -- )
  A-MAPI!           ( ptr a len [ idx a -- a ] -- )
  A-FOLD            ( ptr a len b [ b a -- b ] -- b )
  A-FOLDI           ( ptr a len b [ b idx a -- b ] -- b )
  A-SCAN!           ( ptr n len n [ n n -- n ] -- )
  A-SCAN1!          ( ptr n len [ n n -- n ] -- )
  A-FIND-INDEX      ( ptr a len [ a -- bool ] -- n )
  A-FIND-INDEXI     ( ptr a len [ idx a -- bool ] -- n )

Use typed locals for the array pointer:

  : ARR-SUM ( ptr a n -- i64 ) {: arr:ptr len :}
    arr len >LEN 0 [: + ;] A-FOLD ;

  : SQ-EACH ( ptr a n -- ) {: arr:ptr len :}
    arr len >LEN [: dup * ;] A-MAP! ;

  : ARGMAX ( ptr a n -- i64 ) {: arr:ptr len :}
    arr len >LEN A-ARGMAX IDX>N ;

  : PREFIXSUM ( ptr a n -- ) {: arr:ptr len :}
    arr len >LEN A-PREFIX-SUM! ;

Rules: pass both `arr` and `len >LEN` to checked array helpers, and pass
indexes as `i >IDX`. Index-aware quotations receive `idx`; use `IDX>N` only
when numeric arithmetic or comparison is needed. For an array->array task,
MODIFY THE ARRAY IN PLACE; do not return anything. For an array->scalar task,
leave exactly one integer. Output ONLY the definition. No prose, no code fences.
