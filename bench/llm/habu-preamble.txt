You write habu, a checked stack-based language (Forth-like). Define a word with:

  : NAME ( in -- out ) {: locals :} body ;

A CHECKER verifies the body's real stack effect; a mismatch is REJECTED with a
diagnostic. Tasks operate on an INTEGER ARRAY passed as a POINTER and a LENGTH.

POINTERS & MEMORY (the important part):
- Bind the array pointer to a TYPED local: `{: arr:ptr len :}` — the `:ptr` is required
  so the checker knows `arr` is a pointer (untyped locals are plain integers).
- Address of element i:  `i cells arr +`   (push index*8, then the pointer, then +).
  Pointer + integer stays a pointer; `cells` converts an index to a byte offset.
- Read element i:   `i cells arr + @`        ( @  reads the cell at a pointer )
- Write v to element i:  `... value ... i cells arr + !`   ( !  stores value at pointer )
- The first element:  `arr @`  (same as `0 cells arr + @`).

LOOP over the array (index `i` runs start..limit-1; `i` pushes the current index):
  len 0 ?do  ... i ...  loop

CONDITIONS need an explicit boolean: `dup 0 <>`, `x 0 >`, `a b =` (these yield a flag).
  if:  <flag> if ... else ... then    ( both branches leave the same stack shape )

Other words: + - * / mod max min ( i64 i64 -- i64 ); 1+ 1- negate abs ( i64 -- i64 ).

In a SIGNATURE, an array pointer parameter is written `ptr a` (the word `ptr` plus an
element-type variable), so an (array, length) input is `ptr a n`.

Worked example — sum an array (pointer + length -> one integer):
  : ARR-SUM ( ptr a n -- i64 ) {: arr:ptr len :}
    0  len 0 ?do  i cells arr + @  +  loop ;

Worked example — square each element IN PLACE (pointer + length, no result):
  : SQ-EACH ( ptr a n -- ) {: arr:ptr len :}
    len 0 ?do  i cells arr + @ dup *  i cells arr + !  loop ;

Rules: for an array->array task, MODIFY THE ARRAY IN PLACE (write results back with !);
do not return anything. For an array->scalar task, leave exactly one integer. Output ONLY
the definition. No prose, no code fences.
