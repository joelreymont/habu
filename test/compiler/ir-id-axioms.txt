# Expected external assumptions for the compiler identity proofs.
#
# One row per proved statement in formal/Common/Ids.v, IdAllocator.v, IdLaws.v
# and IdAllocatorLaws.v, in the order those files declare them and in the order
# formal/_CoqProject builds them. `closed` is Rocq reporting "Closed under the
# global context". An `axiom` row is one external assumption, written exactly as
# Rocq prints it.
#
# The parity gate in test/compiler/ir-id-proof.f uses this file twice. It reads
# the theorem names out of it and asks Rocq for the assumptions of each, then
# compares what Rocq answered against this file as a whole - not as a subset,
# and in this order. It also walks the four proof sources structurally and
# requires the statements declared there to be exactly these names, so a new
# theorem cannot arrive unbound and a removed one cannot go unnoticed.
#
# Lines starting with `#`, and blank lines, are commentary. Everything else is
# compared byte for byte.
