# What the compiler identity proofs state, and what they rest on.
#
# One `theorem` row per proved statement in formal/Common/Ids.v, IdAllocator.v,
# IdLaws.v and IdAllocatorLaws.v, in the order those files declare them and in
# the order formal/_CoqProject builds them. Every `theorem` row is followed by
# exactly one `type` row, and then by its assumption rows: `closed` is Rocq
# reporting "Closed under the global context", and an `axiom` row is one
# external assumption, written exactly as Rocq prints it.
#
# A `type` row is this file's copy of what that theorem states, written as Rocq
# prints the statement in the environment the generated obligations file sets
# up: Stdlib Bool, Lia, ZArith, List and Sorting.Sorted imported, the four Habu
# identity modules imported, list notations imported, and Z and bool scopes
# open. The parity gate turns each row into
# `Definition pinned_statement_<k> : <type row> := <theorem name>.` in the file
# it asks Rocq to compile, so Rocq's own type checker decides whether the
# statement in the proof file still is the statement written here. It decides
# that up to conversion, so renaming a bound variable is not a change but
# weakening, strengthening, or trivialising a statement is. These rows are the
# authority: the generated file is a build output and never reads a statement
# out of the proof sources, so changing a proof file alone cannot move the
# target it is checked against.
#
# The parity gate in test/compiler/ir-id-proof.f uses this file three times. It
# reads the theorem names out of it and asks Rocq for the assumptions of each,
# then compares what Rocq answered against the `theorem`, `closed` and `axiom`
# rows as a whole - not as a subset, and in this order. It pins each statement
# with the `type` row beside it. And it walks the four proof sources
# structurally and requires the statements declared there to be exactly these
# names, so a new theorem cannot arrive unbound and a removed one cannot go
# unnoticed.
#
# Lines starting with `#`, and blank lines, are commentary. A `type` row is
# handed to Rocq. Every other row is compared byte for byte.
