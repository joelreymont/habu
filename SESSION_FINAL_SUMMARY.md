## 🔧 Technical Details

### Stack Limitation Discovered

**Issue**: Deep function call nesting causes stack overflow
- 4-byte instruction: ✅ Works
- 8-byte instruction: ❌ Crashes (too deep)

**Solutions**:
1. **Increase C stack size** (quick fix)
   - Add compiler flag: `-Wl,-stack_size,0x1000000`
   - Or use `ulimit -s` on Linux

2. **Iterative approach** (robust)
   - Build lists iteratively instead of recursively
   - Use accumulator pattern

3. **Trampolining** (advanced)
   - Convert deep recursion to iteration
   - Use continuation-passing style

**Chosen approach**: Will increase stack size for now, refactor if needed.

### Machine Code Format

**x86_64 Instruction Format**:
```
mov rax, immediate64:
  Opcode:   48 B8
  Value:    [8 bytes, little-endian]

ret:
  Opcode:   C3
```

**Habu Representation**:
```lisp
;; As list of bytes (base 10):
(72 184 160 2 0 0 0 0 0 0)

;; Or hex equivalents:
;; (0x48 0xB8 0xA0 0x02 0x00 0x00 0x00 0x00 0x00 0x00)
```
