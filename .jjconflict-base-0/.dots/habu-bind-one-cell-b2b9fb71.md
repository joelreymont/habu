Problem: generic effects can leave an output family open until input unification closes its arguments. The checker must admit the one safe logical bind and then materialize each installed output row without creating a second representation or rebuilding unchanged row spines. Rejected candidates 6279afc7b3a4 and 5e7ca42b2de either bound the hidden runtime term directly or rebuilt every row node.

The only new bind lives in U-ROW-DESCEND. It applies when UNIFY-KIND is UK-INPUT, CUR-STRICT is zero, LAYOUT-XPORT is zero, the actual row element resolves to a closed, non-linear, hidden layout of width one, and the expected row element is an unresolved TVK-ANY variable. Bind the expected variable to MK-LOGICAL(actual) and do not enqueue the resulting hidden/logical pair. Every other pair follows the existing descent. Do not relax U-TYPE or LAYOUT-BLOCK?. RAW variables, reverse input order, exact or coerce unification, pointers, linear or open layouts, transport operations, and variables inside family arguments remain rejected or unchanged.

Move PUSH-LOGICAL earlier without changing its behavior. Add one private ROW-NORM ( row -- row ) with copy-on-write semantics: inspect the raw row before resolving it, return raw S-ROW tails unchanged, recurse tail-first only through concrete S-PUSH nodes, reuse the original node when its normalized tail is identical and its head needs no PUSH-LOGICAL expansion, and rebuild only the changed prefix from the original head term and normalized tail. A no-change normalization allocates no push or parameter records.

Normalize exactly seven installations: CHECKER-STEP data output; the already installed EFF-APPLY data row after return-input unification; EFF-APPLY return output; RSEXEC data and return outputs; and CF-RECURSE-EFF data and return outputs after all inputs bind. RSCATCH only constrains quotation rows against existing caller rows and installs no effect output. THROW-EDGE snapshots the existing caller rows before RSEXEC success outputs are installed. Control joins use exact UNIFY and reinstall existing branch rows. EFF-QUOT, CF-SEMIQ, and IS-APPLY construct or carry quotation values rather than perform a bind-then-install transition. None receives ROW-NORM.

Production fixtures in test/type-ctor-suite.f use one compact ENUM tag plus lib/adt/option.f and lib/adt/result.f. Prove the tag through a generic ( a -- a ) identity, OPTION:SOME followed by MATCH, and OPTION:SOME produced by a quotation and execute before MATCH. Use separate exhaustive result consumers: result<tag,n> for RESULT:OK and result<n,tag> for RESULT:ERR. The rejected result<tag,tag> fixture cannot exercise this bind because PARAM-PAIR-ARGS sends family arguments directly to U-TYPE. Negative anchors keep ptr a versus ptr tag rejected in both directions, prevent raw here ! / here @ from minting tag, and prevent a one-cell linear STRUCTURE from passing the generic identity.
