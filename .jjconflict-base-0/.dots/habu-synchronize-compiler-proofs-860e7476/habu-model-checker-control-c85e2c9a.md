Full context: formal/Common/Effects.v models the effect language - types, stacks, unification, sequential composition, and the implicit-row seal - and is verified against src/core/checker.f. It deliberately stops at straight-line bodies. Control flow is absent, and that is the largest gap between the model and the checker: branch joins are exactly where a stack discipline breaks, so a soundness theorem built on Effects.f alone would say nothing about any word containing an if, which is nearly all of them. Scope: extend the formal model with the checker's control-flow constructs, as CF-IF, CF-ELSE, CF-THEN, CF-BEGIN, CF-UNTIL, CF-WHILE, CF-REPEAT, CF-EXIT and CF-RECURSE are dispatched at src/core/checker.f:8356-8378. Model arm agreement at a join and the failure the checker reports when arms disagree (MD-JOIN, checker.f:8165, raised at :8278); loop stack-neutrality for the begin/until and begin/while/repeat shapes; EXIT as an early return that must match the declared output; RECURSE against the declaration; and dead-path handling after EXIT, which the checker tracks via DEAD-OWNER! at checker.f:9079. Model quotation APPLICATION too, not just quotation types - Effects.v models the type but never applies one. Build the model from src/core/checker.f, not from prose, and verify each rule against bin/hb with a real definition that certifies or is rejected; where the code and any document disagree, follow the code and record the divergence, as the previous leaf did for docs/effects.md. Acceptance: Rocq 9.2 compiles it via formal/Makefile after one line is added to formal/_CoqProject; definitional examples cover a joining branch, a branch whose arms disagree and is rejected, a stack-neutral loop, a loop that is not neutral and is rejected, EXIT matching and failing the declared output, dead code after EXIT, and quotation application; each example is cross-checked against bin/hb; no theorem beyond definitional examples and no Admitted. Ownership: the new control-flow file and its _CoqProject line only; do not edit Effects.v except through a reviewed dependency repair, and do not edit any Habu source. Excludes the soundness theorem itself, which follows once acceptance can be stated for bodies containing branches.
