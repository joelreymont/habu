The second half of habu-collapse-branch-chains-63fbc39a, which that lane did NOT do and which is unmeasured rather than refuted. The lane's first cleanup - redirect a branch whose target is a block that emits nothing, and drop the block - took the corpus from 52 internal unconditional branches to 28 and from 2876 bytes to 2780, and it subsumed every opportunity the idle column could see (a branch whose target is the instruction already after it: now 0 across all 54 migrated rows). What it does NOT address is a block with exactly ONE predecessor that the greedy trace laid somewhere else: the predecessor then needs a real branch to reach it, and laying it immediately after its only predecessor would delete that branch by fall-through. ORDER-BLOCKS (src/compiler/native/emit.f) follows only the TAIL successor - the block a terminator's trailing unconditional branch names - falling back to the lowest unlaid block, so the taken arm of a conditional is never followed and a single-predecessor block reached that way is laid wherever the fallback puts it. Measure before building, as the first half did: 28 unconditional branches survive across the corpus, and the question is how many of them enter a block whose only predecessor is the block the branch sits in. tools/codegen-branch-inventory.f already counts the branches (the b column); the predecessor counts come from the frozen module's published edge tables (IR-BUILD:FEDGE-ROWS with IR-VERIFY:FPRED-COUNT, src/compiler/ir/verify.f:937-958 - readable after freeze and so far used only by test/compiler/ir-verify.f), so no fourth predecessor scan is needed. If the count is zero, that is the deliverable and this dot closes as a measured zero. Care: the return block must stay last (RET-ORD and the record convention NPUB depends on), block zero must stay first, and the order must remain one permutation of the kept blocks so LAYOUT and WALK still agree - CURSOR-CK is what catches a partial job. Acceptance: a measured count of the opportunity first; then, if non-zero, the branch count falls with answers bit-for-bit and no untouched row moving. Depends: none. Ownership: src/compiler/native/emit.f ORDER-BLOCKS. Claim: unassigned.
