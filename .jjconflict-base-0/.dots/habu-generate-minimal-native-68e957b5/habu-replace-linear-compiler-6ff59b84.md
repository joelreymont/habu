Measured at master 3909bbac, excluding MATCH and the separately owned pass-2 family. The first-pass compiler emits 86 retained non-MATCH keyword rows: 59 CF/CFN/CFB/CFBN rows plus 27 JIT operator rows. Every row begins with the identical four-instruction ADR keyword; MOVZ length; BL LKWCMP; CBZ miss scaffold. That is exactly 86 x 16 = 1376 bytes before any handler work. SHAKE? is zero for the standard engine, and a late miss executes LKWCMP sequentially up to 86 times. Root cause: source-level entry factoring only factors the metacompiler, while the generated target remains a linear chain of duplicated comparisons. Fix: emit one compact case-folded length/hash dispatch over the retained keyword set, returning a packed action kind/target consumed by shared control, string, meta, loop, arithmetic, comparison, float, shuffle, and unary handler stubs. Generate the table from the existing retained rows; do not hand-maintain a second keyword list. Require a measured net reduction after table bytes, collision checks, and shared dispatcher code. Preserve the enclosing precedence of ADT mode, semicolon, locals, keywords, literals, dictionary calls, and undefined-word handling. Acceptance: disassembly contains one lookup rather than 86 comparator prefixes; exact region attribution proves net shrink; every spelling and case variant, adversarial collision/near miss, unknown word, all handler kinds, KEEP?-reduced build, precedence edge, and compile error path matches current behavior; compile-throughput improves or stays within the measured PERF-VERDICT band; bootstrap mirror, AOT, snapshot, fixpoint x2, both targets, full compiler/checker suites, host/dot lints, and exact size ratchets pass. The 20 pass-2 keyword rows stay with habu-engine-compaction-measured-1bef27f6 to avoid duplicate ownership. Files: src/habu/habu2.f, src/habu/jit.f, generated keyword data/dispatch, bootstrap/cg/forth.fs, compiler dispatch tests, performance verdict, and size gates.
